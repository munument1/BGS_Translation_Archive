# Morrowind

The Elder Scrolls III: Morrowind 번역 데이터 아카이브입니다.

권장 하위 구조:

```text
BaseGame/   본편 번역
DLC/        공식 DLC 및 공식 추가 콘텐츠
Mods/       모드 번역
```

실제 데이터가 추가되는 범주부터 하위 폴더를 생성합니다.

## 본편 한국어 번역 버전 정책

**사용자의 최신 기준은 OpenMW 모로윈드 한국어판 KR9입니다.**
이전에 임시 이관했던 **KR6 자료는 현재 아카이브에서 제외**했습니다.
이 저장소에 KR6 기반 번역 항목이나 용어를 신판으로 자동 합치지 않습니다.

- 공식 KR9 릴리스 ZIP과 한국어 ESP SHA-256을 검증했습니다.
- BaseGame/KR9/translation.jsonl: KR9 ESP, OpenMW l10n, CEL/TOP/MRK/JRN에서
  추출한 총 53,896개 한국어 항목입니다. 원본 영어 전문은 미수록했습니다.
- BaseGame/KR9/metadata.json: 릴리스 및 플러그인 SHA-256과 검증 범위입니다.
- KR9에 존재하지 않는 한국어 대사는 이전 KR6에서 임의 보완하지 않습니다.
- 다른 게임과 용어를 비교하더라도 모로윈드 본편 원전은 KR9로 지정합니다.
- 저장소의 과거 Git 커밋에는 이전 KR6 임시 기록이 남아 있을 수 있지만,
  현재 기본 브랜치의 기준 번역으로 사용하지 않습니다.
