# Fallout 4

Fallout 4 번역 데이터 아카이브입니다.

권장 하위 구조:

```text
BaseGame/   본편 번역
DLC/        공식 DLC 및 공식 추가 콘텐츠
Mods/       모드 번역
```

실제 데이터가 추가되는 범주부터 하위 폴더를 생성합니다.

## 본편·공식 DLC 한국어 자료

사용자가 제공한 Fallout4_Korean_20260819 패치의 Steam 1.11.240
본편과 공식 DLC 6종, UI 사전에서 **164,201개 한국어 항목**을
추출하여 압축 JSONL로 아카이브에 보관했습니다.

`BaseGame/KoreanPatch-20260819/archive/`의 `*.ko.jsonl.gz`
22개에 실제 한국어 문장을 무손실 저장했습니다.
`BaseGame/import_metadata.json`과 각 `manifest.json`에는
출처·원본 해시·건수·압축본 복원 검증값을 기록했습니다.

공개 배포 패치 보존을 요청받아 수록했지만 동봉 README에
번역 기여자 명단과 라이선스가 명시되어 있지 않습니다.
이는 사용권 허가나 무제한 재배포 권한을 선언하는 것이
아닙니다. 정확한 기여자가 확인되면 출처를 보강하며,
권리자 요청은 저장소 관리자가 검토해야 합니다.
