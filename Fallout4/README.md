# Fallout 4

Fallout 4 번역 데이터 아카이브입니다.

권장 하위 구조:

```text
BaseGame/   본편 번역
DLC/        공식 DLC 및 공식 추가 콘텐츠
Mods/       모드 번역
```

실제 데이터가 추가되는 범주부터 하위 폴더를 생성합니다.

## 본편·공식 DLC 한국어 자료

사용자가 제공한 Fallout4_Korean_20260819 패치의 Steam 1.11.240
본편과 공식 DLC 6종, UI 사전에서 **164,201개 한국어 항목**을
추출해 로컬에 보관했습니다.

공개 저장소의 BaseGame/import_metadata.json에는 파일 출처,
패키지가 주장하는 게임 버전, 구조 검증·건수만 수록합니다.
패치 번역 기여자 및 재배포 허가가 확인되지 않아 한국어 문자열
전문은 공개 저장소로 복제하지 않았습니다.
