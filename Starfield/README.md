# Starfield

Starfield 번역 데이터 아카이브입니다.

권장 하위 구조:

```text
BaseGame/   본편 번역
DLC/        공식 DLC 및 공식 추가 콘텐츠
Mods/       모드 번역
```

실제 데이터가 추가되는 범주부터 하위 폴더를 생성합니다.

## 본편 한국어 번역 자료

사용자가 제공한 Starfield_Koreanpatch_260914의 본편 3종 문자열
테이블 및 UI 사전을 로컬에서 검증해 **182,448개 한국어 항목**을
추출했습니다. 식별자는 실제 문자열 ID와 UI 키를 유지합니다.

`BaseGame/KoreanPatch-260914/archive/`의 `*.ko.jsonl.gz`
4개에 실제 한국어 문장을 무손실 저장했습니다.
`BaseGame/import_metadata.json`과 `manifest.json`에는
출처·SHA-256·건수 및 복원 검증값을 기록했습니다.

팀 왈도의 스타필드 한국어 패치 공개 배포 이력이 있으나
이 로컬 패키지가 그 공식 배포본과 동일한지, 모든 번역 기여자가
누구인지 확정하지는 못했습니다. 해당 번역문을 자유 라이선스로
재허가하는 것이 아니라 공개 아카이브 자료로 보관합니다.
권리자·기여자 출처 요청이 있으면 관리자가 검토해야 합니다.
