03 / BEYOND THE ARCHIVE

아직 서가에 없는
탐리엘의 기록들.

The Imperial Library의 Game Books를 참고하여, 기존 네 작품 서고에 들어 있지 않은 다른 게임의 문헌을 찾는 공간입니다. 우선 《엘더 스크롤 온라인》의 확인된 외부 서적 7종을 소개합니다.

외부 자료 · 출처 링크 모음 — 아래는 한국어 제목 제안과 독자적인 짧은 소개입니다. 전체 서적을 번역·복제한 것이 아니며, 게임 원문의 재배포 권한이 확인되면 별도의 번역 검수 절차를 거쳐 본문 수록 여부를 판단합니다.
