# ESO 한국어 게임 본문 보충

2026-10-28 사용자 제공 `kr.lang`에서 **3,847개**의 기존 한국어 게임 본문을 탐리엘의 서고에 연결했습니다. 새 번역을 생성한 것이 아니라 제공된 번역을 수록한 것입니다. 3,847개는 기존 서지 항목 기준이며, 고유 게임 책 ID는 3,826개입니다. 동일 게임 기록을 가리키는 기존 서지 항목의 UID와 주소는 유지합니다.

| 서가 | 한국어 보충 | 현재 읽기 목록 |
|---|---:|---:|
| ESO 일반 서적 | 1,946 | 2,528 |
| ESO 일지·쪽지·편지 | 1,901 | 2,232 |
| 합계 | 3,847 | 4,760 |

47개는 영문 본문 미확보로 기존 읽기 목록에 없던 자료이며, 한국어 본문으로 새로 추가했습니다. 기존 영문 4,782개와 이번 한국어 전용 47개를 합쳐 외전·온라인 추가 서가에는 총 4,829개가 있습니다. ESO 중 영문만 남은 읽기 자료는 913개입니다. 제공 파일 전체의 번역률이나 ESO 게임 전체의 서적 수를 뜻하지 않습니다.

## 연결 방법

- `.lang` 버전 2의 빅엔디언 인덱스를 읽고, 제목 그룹 `51188213`과 본문 그룹 `21337012`를 동일한 책 ID로 연결했습니다. 파일에서 제목 7,490개와 본문 7,487개를 확인했습니다.
- [LoreBooks의 책 ID·영문 제목 목록](https://github.com/ESOUIMods/LoreBooks/blob/514e66547f72ae48a8da8d7d0f0dce4b0e448fc0/PC/EideticData.lua)을 기존 서지 원제와 대조했습니다. 대소문자·구두점·공백·`[ESO]` 표기만 정규화하며 권 번호는 보존합니다. 제목이 유일하거나 복수 ID의 한국어 본문이 완전히 같을 때만 연결합니다.
- 한국어 본문은 **게임 레코드 판본**입니다. 기존 Imperial Library 영문 편집본과 문단·권 구성·판본이 같다고 주장하지 않습니다. 웹 카드와 읽기 화면에는 `기존 게임 번역`, 책 ID, 출처 안내를 표시합니다.
- 기존 서지 UID·영문 자료·출처는 보존합니다. 한국어 제목·본문은 검색 색인과 개별 Markdown·합본·JSONL에 반영합니다. 기존 외전 번역은 유지합니다.
- 게임 색상·정렬 표식은 제거합니다. 삽화·도안은 안내 문구로 표시하며 `<<1>>` 같은 실행 시 치환 변수는 그대로 남기고 읽기 화면에서 안내합니다. 원본 본문·제목의 SHA256과 제공 파일 SHA256을 보존합니다.

## 남은 범위

기존 ESO 서지 4,766개 중 906개는 현재 ID 목록의 영문 원제와 고유하게 대응하지 않으며, 13개는 같은 제목에 서로 다른 게임 본문이 있어 연결을 보류했습니다. 이 919개를 게임 번역 누락이나 미번역 수로 해석하지 않습니다. 원제 대응 자료와 판본을 추가 확인해야 합니다. 제목만 닮은 항목에 다른 본문을 넣지 않습니다.

제공된 파일의 정확한 제작 판본·번역자 목록은 확인하지 않았습니다. 사용자 제공 ESO 한국어 패치로 출처를 명시하며, [ESO 한국어 번역 프로젝트](https://esokr.org/)를 참고 링크로 제공합니다. 개별 문장 검수나 인게임 전수 검증을 마쳤다는 뜻은 아닙니다. 약 104MB의 원본 `.lang`과 비서적 대사·UI 문자열은 공개 저장소에 넣지 않습니다.
