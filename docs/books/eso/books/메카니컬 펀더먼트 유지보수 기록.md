# 메카니컬 펀더먼트 유지보수 기록

ID: ext-e0eadcbfe81b0bac5181 / ESO 책 ID: 4589 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

팩토텀은 메카니컬 펀더먼트 내의 모든 유기물을 수거하라는 명을 받았다. 사망자 열일곱 구도 포함된다. 모든 화폐와 신원 확인이 가능한 물품은 치안 폐기 보관소로 인계할 것. 임무 완료 즉시 기록된 모든 데이터를 말소하라.
