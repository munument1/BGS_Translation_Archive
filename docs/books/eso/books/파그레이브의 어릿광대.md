# 파그레이브의 어릿광대

ID: ext-f2358ac4f6f648a848c9 / ESO 책 ID: 6588 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(윔 부인의 의뢰로 음유시인 티라시에 미렐이 쓴 은둔자에 관한 노래. 은둔자를 비하하는 유머러스한 작품이 될 예정이었으나, 음유시인은 윔의 지시를 따르면서도 골목의 사랑받는 이를 기리기 위해 최선을 다하였다.)
