# 공포의 아버지의 거짓말

ID: ext-206bed24348d7d7d0aff / ESO 책 ID: 5361 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

니스우 제울름 지음  
  
둥근 혀들이 그것에 형상과 모습을 부여하니  
그것은 그로 변하노라  
그들은 그의 썩어가는 신부에게 속삭이는 자  
그를 기리라고, 그를 숭배하라고  
  
그들은 그것을 아버지라 이름하니, 그토록 두려운 존재여  
그들은 두려운 피의 칼날을 들고 기도한다  
그들은 진실의 한 단면만을 말하니  
무언가가 그들의 혀에 들러붙어 있노라  
  
무형이 형상을 얻고  
변화는 정체로 굳어지며  
하나의 진실은 거짓이 되니  
어떤 눈들의 형제단이로다
