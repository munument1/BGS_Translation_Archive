# 게어문드의 맹세

ID: ext-5ee03ba1165981dbf64f / ESO 책 ID: 1018 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

위대한 전투마법사, 게어문드 경께서  
하랄드의 시대에 리프트를 구하셨네.  
  
악독한 갈두르 삼형제를 베어 넘기시고,  
그 아비의 혼백을 풀어 주셨네.  
  
그분의 무덤은 이 호숫가에 세워졌으니,  
그 이름을 받들어 나 이 맹세를 하노라.  
  
악이 닥쳐오고, 밤이 내려앉을지라도,  
내 리프트를 지키리라 맹세하노라.
