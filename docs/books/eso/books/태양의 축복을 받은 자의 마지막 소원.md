# 태양의 축복을 받은 자의 마지막 소원

ID: ext-64b78adaeb39a9fc71cd / ESO 책 ID: 5375 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

솔리스 아두로 옮김  
  
비록 광휘로운 영광에 잠겼으나  
황금과 수피의 피부를 지녔어도  
우리는 노른자에 미치지 못하였고  
이제는 너무 늦었노라  
  
허나 어둠 없는 빛은 눈을 멀게 하고  
그림자는 언제나 우리를 굽어살피나니  
우리가 바라기만 한다면, 그것은 지금 우리 곁에 있도다  
빚을 갚는 노역이 비록 길지라도  
  
우리는 그래야만 하리, 황금 비늘이여  
우리는 심연의 형제들과 하나가 되어야 하리  
아무리 많은 것을 잃는다 해도  
  
우리의 뿌리는 인내하나니  
우리는 다시 일어서리라  
이 세상에서, 혹은 다음 세상에서
