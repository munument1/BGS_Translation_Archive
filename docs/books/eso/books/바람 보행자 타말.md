# 바람 보행자 타말

언제나 충직하였던 타말,  
재치는 빠르고 쓰러짐은 더디니,  
그의 벗들은 그리 기억하노라.  
  
그는 더없이 우아하게 칼을 휘둘렀고,  
얼굴엔 고요한 가면을 드리웠으니,  
그의 적들은 그리 기억하노라.  
  
<<1>>의 충직한 수행원이었기에,  
명예의 빚은 한 점 갚지 못함이 없었으니,  
모두가 그리 기억하리라.
