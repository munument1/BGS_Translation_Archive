# 갈리도어의 사랑 시

ID: ext-66ec828ae5e0f4af2eb3 / ESO 책 ID: 4718 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

오, 사랑스러운 자바나여,  
그대도 알 테지,  
그대와 세 생을 함께하고픈 이 마음을.  
  
허나 내 주머니는 텅 비었고,  
내어줄 것 하나 없으며,  
돈도 없고, 신발엔 구멍만 났네.  
  
허나 언젠가, 그대도 알듯이,  
우리 함께 떠나리,  
깊고 푸른 참나무 숲으로.  
  
뿌리 사이에 몸을 누이고,  
그랏베리 열매를 따 먹으리,  
왕과 그의 왕비처럼.
