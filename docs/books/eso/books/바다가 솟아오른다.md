# 바다가 솟아오른다

ID: ext-34b1761660958199125c / ESO 책 ID: 2074 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(긴 해안의 뱃노래)  
  
바다는 우렁찬 으르렁거림으로 솟구치고  
바람은 머나먼 해안에서 불어오네  
파도는 우리 갈 길을 재촉하고  
배는 물보라 속에서 춤을 추네!  
  
모두 활대 밧줄로, 끌어올려라!  
돛을 활짝 펼쳐라, 지체는 없다!  
정한 항로를 우리는 곧게 나아가야 하리  
아니면 짠 푸른 바다에 스스로 가라앉으리!  
  
해변 너머 저 항구를 바라보라  
우리의 목적지에 닿으리니  
우리 선장의 의지는 강철이라  
그 믿음을 저버리면 용골에 입을 맞추리라!  
  
바다는 해안에 잔잔히 가라앉고  
바람은 다시는 우릴 밀어주지 않으리  
파도는 고요하고, 물보라도 없으니  
우리 배는 훗날 다른 날에 떠나가리.
