# 묘비 쪽지

ID: ext-a246863522c6a0dc2ed1 / ESO 책 ID: 2063 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

이름: 윌람, 가이문드, 올리비아, 조엘  
성: 모레, 라바르뉴, 쇼브리, 레르니스  
직업: 마법사, 사제, 도둑, 전사  
  
묘비에 적힌 이름의 순서는 다음과 같다:  
조엘 …  
가이문드 쇼브리  
… 모레  
윌람 …  
  
마법사의 편지는 라바르뉴 앞으로 쓰였으니, 라바르뉴는 마법사일 수 없다.  
조엘의 묘비에 따르면 그녀는 전사였으며, 사제가 그녀와 가장 가까이 묻혀 있다.  
모레의 묘비에 따르면 모레는 마법사도 전사도 아니었다.
