# 루디 맨의 시

ID: ext-f63e630242cd412a41b9 / ESO 책 ID: 4534 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(던머의 동요)  
  
루디 맨이 돌아다닐 땐 명심하렴  
비명도 못 지르고 소리도 못 치네  
달아날 수도, 숨을 수도 없다네  
그러려던 이들은 벌써 다 죽었으니!  
  
루디 맨이 즐겨 먹는 음식은 뭘까?  
던머의 눈알과 던머의 발이지!  
던머의 혀와 던머의 발가락이지!  
아무리 숨어 봐도 루디 맨은 다 안다네!  
  
루디 맨은 언제 놀러 나올까?  
하늘이 어둑하고 잿빛이 될 때면 언제나!  
저 광산에 있나, 아니 저 동굴에 있나,  
너를 무덤으로 보내고 싶어 안달이라네!  
  
위대한 루디 맨을 누가 무찌를까?  
우리의 비벡 경, 바로 그분이지!  
루디 맨을 베고 찔러 꿰뚫어 버리고  
그러고는 루디 맨으로 스튜를 끓이시지!
