# 명예 전역 통지서

ID: ext-27b66735e3ef0f9c5898 / ESO 책 ID: 1589 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

아베시안 해적의 습격에 맞선 <<1>>의 행적은 마땅히 최고의 영예로 기려야 한다. 최전선에 서서 그는 휘하 병사들을 북돋아 전술적으로 결정적인 방어선을 지켜내게 하였다. 이 분투 덕분에 수많은 민간인이 안전하게 물러날 수 있었고 적은 격퇴되었다. 허나 이 방어에는 대가가 따랐으니, <<1>>은(는) 두 형제를 비롯하여 많은 병사를 잃었다.  
  
전통대로라면 이러한 공적에는 공로를 기리는 현장 진급이 마땅하나, <<1>>은(는) 군역에서 물러나기를 청하였다. 여러 해에 걸친 <<1>>의 복무와 근래 보여 준 용맹을 헤아려, 지휘관들은 <<1>>의 청을 받아들였다.  
  
이로써 <<1>>에게 최고의 영예를 더하여 군역에서 면함을 명하노라.
