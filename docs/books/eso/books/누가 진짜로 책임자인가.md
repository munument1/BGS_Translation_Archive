# 누가 진짜로 책임자인가?

ID: ext-701abb8b9c5eb9a7d451 / ESO 책 ID: 2974 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

진실을 좇는 자 브루가기크 저  
  
나는 탐리엘의 모든 대도시 아래 숨겨진 지하 묘역에서 암약하는 엘리트 마법사들의 은밀한 비밀 결사가, 탐리엘 전역을 손아귀에 넣으려는 음흉한 계략의 일환으로 이른바 '차원융합'이라는 것을 꾸며 냈다는 결정적 증거를 손에 넣었다.  
  
'몰라그 발' 따위는 없다. 그자는 신화일 뿐이다. 교묘하게 지어낸 허구다. 저 '다크 앵커'들이란 실은 이 결사가 만들어 세상 곳곳에 심어 놓은 정신 지배 장치에 불과하다. 무슨 일이 있어도 저 장치에는 다가가지 마라. 그것은 너로 하여금 환각을 일으켜 온갖 괴물과 악마를 보게 하고, 끝내 제 검 위에 쓰러져 스스로 목숨을 끊게 만들 공산이 크다.  
  
세 연합의 지도자는 모두 이 결사의 존재를 알고 그것을 비호하고 있다. 아니, 그들 자신이 죄다 현역 조직원이다. 결코 속지 마라.
