# 에일의 전투

ID: ext-c294001b244c0f5ecf6b / ESO 책 ID: 784 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

오늘 나는 잔의 전투에서 이겼네,  
잔의 전투에서 이겼네!  
높이 치켜들고는,   
단숨에 비워버렸네—  
잔의 전투에서 이겼네!  
  
오늘 나는 물주전자의 전투에서 이겼네,  
물주전자의 전투에서 이겼네!  
높이 치켜들고는,   
단숨에 비워버렸네—   
물주전자의 전투에서 이겼네!  
  
오늘 나는 통의 전투에서 이겼네,  
통의 전투에서 이겼네!  
높이 치켜들고는,   
단숨에 비워버렸네—  
통의 전투에서 이겼네!  
  
오늘 나는 에일의 전투에서 졌네,  
에일의 전투에서 졌네.  
나는 들이켰고,  
에일은 나를 쓰러뜨렸네—  
  
나는 에일의 전투에서 졌네 ….
