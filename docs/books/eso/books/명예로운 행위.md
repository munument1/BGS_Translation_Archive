# 명예로운 행위

ID: ext-204b8de72adfb222d90e / ESO 책 ID: 5363 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

니스우 제울름 지음  
  
그대가 일구는 밭을 통하여  
부서진 대지를 통하여  
그대가 키워 낼 작물을 통하여  
변화인 그것을 기려라  
  
말 없는 말을 들으라  
수많은 혀를 들으라  
그 모든 것 속에 깃든 하나의 진실을 들으라  
공허인 그것을 기려라  
  
피 묻은 송곳니로  
으스러뜨리는 일격으로  
끊어지는 마지막 숨결로  
죽음인 그것을 기려라
