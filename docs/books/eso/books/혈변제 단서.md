# 혈변제 단서

ID: ext-af571f75b825c98a8061 / ESO 책 ID: 7257 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

리프트의 자작나무 한가운데  
세 부족이 야영지를 꾸린 곳.  
   
우리에 갇힌 포로는 위태롭고  
야생 곰이 쿵쿵 발을 구르네.  
  
달이 그려진 깃발 아래  
그대의 덱을 벼릴 수 있으리.  
  
그곳에 그대의 카드가 잠드니  
돌에 흩뿌려진 핏자국이라.
