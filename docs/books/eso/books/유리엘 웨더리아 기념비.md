# 유리엘 웨더리아 기념비

ID: ext-b992309240ba3662106b / ESO 책 ID: 8045 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

헌신적인 아들이자   
명예로운 전사를 기리는 이곳에 그 추억이 잠들다  
  
그대 끝내 집으로 돌아오지 못하였으나,   
그대를 사랑하는 이들이   
그대의 이름으로 기념비를 세우고자 하였노라  
  
그토록 밝은 빛을 잃은 것은   
언제까지나 비극으로 남으리니,   
그대의 추억은 우리와 함께 살아가노라
