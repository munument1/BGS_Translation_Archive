# 우엘라의 노래

ID: ext-5c4106a6c03e2b600c35 / ESO 책 ID: 1849 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

약탈자 우엘라 지음  
  
구름이 솟고  
봉우리 너머  
폭풍이 부순다  
산비탈을  
바람이 후려친다	  
협곡 벽을  
눈사태가  
골짜기를 훑는다  
사냥꾼은 창으로 찌르고  
동굴 곰의  
살을 찢어  
뼈를 쪼갠다  
브라이어하트여  
리치에서  
  
브레튼은 숨는다  
폭풍의 잔해를 피해  
산을 두려워하고  
추위에 떨며  
마을로 달아나  
지붕 아래 움츠리고  
교회로 가  
무릎을 꿇는다  
빌고 또 비나니  
숨겨 달라, 가려 달라  
기어나오는 건  
날이 따뜻할 때  
죽이고 먹는다  
가엾은 새끼양을  
  
사냥꾼은 창으로 찌른다  
무른 브레튼을  
살을 찢고  
뼈를 쪼갠다
