# 불멸의 아라카울

ID: ext-fda7e8ddd170ea37b011 / ESO 책 ID: 3137 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

족장을 베고 일족을 떠났으니,  
머에게도 인간에게도 굽히지 않은,  
얽매이지 않은 오크여, 영원하라.  
  
떡갈나무 방패를 들고 막아서서,  
끝까지 발로스를 지켜낸,  
충직한 벗이여, 영원하라.  
  
나라를 위해서도, 금화를 위해서도, 왕을 위해서도 싸우지 않았으니,  
형제애가 곧 그의 전부였던,  
야만의 아들이여, 영원하라.
