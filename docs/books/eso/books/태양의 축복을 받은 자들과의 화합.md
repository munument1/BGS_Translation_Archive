# 태양의 축복을 받은 자들과의 화합

ID: ext-0e25acf1880e5bee3c91 / ESO 책 ID: 5372 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

솔리스 아두로 번역  
  
우리는 뿌리의 백성이다. 그것은 다른 어떤 세계에서와 마찬가지로 이 세계에서도 진실이다. 우리의 뿌리는 그림자 속 깊이 뻗어 내려 기억의 물결을 들이켜지만, 우리의 가지는 하늘 높이 솟아올라 태양의 빛을 받는다. 우리는 이제 하나로 뭉쳐, 우리의 비늘 위로 내리쬐는 태양의 온기를 느껴야 한다.  
  
거짓 예언자가 금단의 거짓으로 우리 형제들을 돌아서게 하였다. 그들은 우리의 사명을 저버렸다. 그들은 우리의 운명을 저버렸다.  
  
그대들 모두에게 이르노니, 나와 함께 강을 거슬러 오르라. 그들은 바다 속으로 가라앉도록 내버려 두라. 우리는 영광의 계단을 올라, 태양을 갈라 열리라.
