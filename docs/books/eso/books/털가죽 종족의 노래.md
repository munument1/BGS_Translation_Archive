# 털가죽 종족의 노래

ID: ext-64f0b351518605d90ffd / ESO 책 ID: 5600 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

합창단  
재주 많은 다기, 날랜 수세이, 건장한 파마르, 센치-라트,  
아주라가 선물을 나눠 줄 때, 우리에게 참 많이도 주셨네,  
잘생긴 캐세이, 날쌘 토자이, 몰래하는 오메스와 알피크,  
이리도 다양한 모양과 크기 — 그게 바로 우리만의 독특한!  
  
우리 모두가 사랑하는 다기, 나무 오르기를 좋아하지,  
분홍색 울퉁불퉁한 무릎의 우드엘프보다야 훨씬 낫지,  
가지에서 가지로, 빠르고도 거뜬히 날듯이 건너가며,  
한여름 산들바람에 흩날리는 깃털처럼 아름답네.  
  
합창단  
  
들어 두어라, 좋은 충고 하나: 센치는 건드리지 마라,  
발톱은 면도날처럼 날카롭고 턱은 뼈도 부러뜨리나니,  
눈 한 번 깜짝할 사이에 엘프를 갈기갈기 찢어 놓지,  
죽고 싶을 때라야 싸움을 걸어라!  
  
합창단  
  
우리의 사랑하는 어머니 아주라께서 알피크를 작은 몸으로 만드셔서,  
웅크리면 도무지 눈에 띄지 않는다네,  
이건 마법이다! 누가 감히 반박하랴?  
카짓이 못 할 일이란 진정 없다!  
  
합창단
