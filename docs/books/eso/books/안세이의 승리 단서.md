# 안세이의 승리 단서

ID: ext-3bf87f40b9fadd57e52a / ESO 책 ID: 7298 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

알리키어 사막을 가로질러  
훈딩이 지켜보는 곳.  
  
영혼은 끝없이 부딪치며, 늘 깨어 있나니  
서쪽 모래 자국 위에서.  
  
유적 한가운데 돌로 두른 서클  
낮이 오든 밤이 오든.  
  
그대의 카드가 여기 잠들어 있으니  
승리를 거둔 싸움이라.
