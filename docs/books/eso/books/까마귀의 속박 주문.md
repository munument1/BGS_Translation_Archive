# 까마귀의 속박 주문

ID: ext-0758dfea4f6dbd2ce1bf / ESO 책 ID: 1620 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

허씬의 올가미와  
나미라의 끈적한 점액의 자취로  
이곳을 결박하노라  
세 번 또 일곱 번  
  
말라카스의 저주와  
베르미나의 해골로  
(희생자의 이름)을 결박하노라  
이 소환의 투기장에  
  
데이건의 면도날과  
몰라그 발의 사슬로  
때가 임박하면  
그대는 나의 부름에 응하리라
