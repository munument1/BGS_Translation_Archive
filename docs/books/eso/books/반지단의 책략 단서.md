# 반지단의 책략 단서

ID: ext-72e0b60df0fe2ba17fcd / ESO 책 ID: 7296 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

그대는 리퍼와 함께 행진하리라  
맹렬한 걸음으로.  
  
아크메이지가 점수를 매기고  
제자리를 잃은 팔리네스티.  
  
작은 웅덩이 곁에  
갈목의 안식처 한가운데.  
  
여기 그대의 단서가 잠드니  
그대를 속이는 반지들이라.
