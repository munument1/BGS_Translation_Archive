더 홀(The Hole)의 규칙:  
  
1. 이곳을 존중할 것. 깨끗하게, 그리고 조용하게 유지할 것.  
  
2. 하루에 최소 몇 시간은 물고기를 골똘히 생각하며 보낼 것.  
  
3. 매머드를 놀리지 말 것!  
  
4. 마시고, 마시고, 좀 더 마실 것.  
  
5. 벌꿀술을 채워 둘 것!
