# 씨직 렐릭마스터 단서

ID: ext-220a750c10374e403315 / ESO 책 ID: 7255 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

아우리돈의 해안을 찾을지니  
완살렌으로 향하라.  
  
굶주림 망자를 베어 넘기며  
물길을 따라 나아가라.  
  
슬픔으로 붉게 물든 잎새 아래  
다크타이드의 힘이 보이는 곳.  
  
그곳에 그대의 카드가 잠드니  
사이직의 권능과 힘이라.
