# 검은깃 하인 단서

ID: ext-104eb0b2bfd6ea721006 / ESO 책 ID: 7219 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

부리가 검고  
나무가 빽빽이 둘러선 곳.  
  
고대의 오두막 하나  
어둑하고 침침하게 서 있네.  
  
텅 빈 화로는  
조금도 빛을 내지 않고.  
  
그대의 카드가 여기 잠들었으니  
까마귀 기사의 부름에 귀 기울이라.
