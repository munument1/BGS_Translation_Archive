# 연구 조사 구함

ID: ext-03ab38c49a223e91be30 / ESO 책 ID: 2017 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

에일리드 유적과 에일리드 우물의 마법적 특성에 관한 비전 연구를 도울 유능한 일손을 구함.  
  
레드퍼 교역소에서 큰길을 따라 북쪽으로 가면 나오는 벌레뿌리 구렁 외곽의 야영지에서 직접 방문하여 지원할 것.
