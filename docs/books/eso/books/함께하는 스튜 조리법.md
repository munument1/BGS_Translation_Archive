# 함께하는 스튜 조리법

ID: ext-fbd5ab5bbf8ae5df8592 / ESO 책 ID: 8308 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

트리일바가 고대 노드어에서 옮기다  
  
자연의 향연, 시간의 향연, 앞으로 또 뒤로 우리는 운율을 지키네  
남들은 우리를 갈라놓으려 하나, 그 순서가 우리 마음에 새겨졌음을 우리는 아네  
시작이 곧 끝일 수 있고, 끝이 곧 시작일 수 있으니  
그러니 꼼꼼히 읽고, 신중히 헤아려, 영리하게 고르라.  
  
윙윙대는 것들의 보물은 우리의 결속을 달콤히 하고, 헤엄치는 자의 비늘은 푹 우러나네.  
깊은 곳의 꽃과 알뿌리로 풍미를 더하고.  
껍데기 속 알맹이가 빛나면 태양이 다시 한 바퀴 돌아오네.  
구석구석 읽으라, 그러지 않으면 그대의 향연은 시시하리라.
