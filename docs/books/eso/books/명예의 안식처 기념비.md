# 명예의 안식처 기념비

ID: ext-dbc6ca812cba90bec48c / ESO 책 ID: 3066 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

이 전당에서 전사들은 안식을 찾고,  
벽에는 영원토록 이름이 새겨지리니,  
결코 잊히지 않으리라.  
  
재와 뼈—여기 그들이 잠들고,  
철과 돌로써 명예가 증명되니,  
결코 잊혀서는 안 되리라.  
  
그 안에 보석보다 값진 보물이 있으니,  
기념의 웅덩이가 베푸는 은혜를 통하여,  
그들은 결코 잊히지 않으리라.  
  
아득히 잊힌 기억을 깊이 들이켜고,  
바래버린 역사에 빛을 비추라,  
그것은 결코 잊혀서는 안 되리라.
