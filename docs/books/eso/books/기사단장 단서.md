# 기사단장 단서

ID: ext-87abd2f4a3226f68c7c7 / ESO 책 ID: 7261 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

그대는 하이 아일로 배를 몰리라  
기사들이 창을 겨루고 부딪치는 곳.  
  
온몸을 갑옷으로 두른  
자못 거만한 지망자들.  
  
웅장한 아치 곁  
공들여 내걸린 방들 사이에.  
  
그대의 카드가 여기 잠드나니  
기사단장의 칼날이라.
