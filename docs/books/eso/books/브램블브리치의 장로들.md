# 브램블브리치의 장로들

ID: ext-2699044cc97b1a919b73 / ESO 책 ID: 1892 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

방적공들은 영들을 이야기하네  
이 땅이 그들의 것이며  
그들이 이 땅에 속한다고  
그들이 무언가에 속하기라도 한다면.  
  
그들은 우리의 선조이며  
우리를 다스리는 이,  
양심이 스러질 때 우리의 양심이요,  
어리석은 엘프를 위한 지혜라네.  
  
우리가 그들과 동떨어져 사는 척할 수는 있어도  
그것은 한낱 어린애의 이야기, 유치한 꿈으로 빚어낸 것에 불과하네.
