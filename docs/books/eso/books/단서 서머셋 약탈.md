# 단서: 서머셋 약탈

ID: ext-8594fc8a61b0042e78c5 / ESO 책 ID: 7254 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

그대는 아우리돈으로 날아가리  
마오머가 배를 대는 그곳으로.  
  
빛이 처음 하늘에 닿는 곳  
모래로 깃을 두른 긴 해안을 따라.  
  
거대한 돌 아치 아래  
다만 싸움을 치러야 할지도 모르리.  
  
그곳에 그대의 카드가 놓여 있으니  
마오머의 횃불이 날아오르는 곳에.
