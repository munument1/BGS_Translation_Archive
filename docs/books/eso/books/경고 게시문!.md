# 경고 게시문!

ID: ext-a087601cfc6bf2f05ba8 / ESO 책 ID: 8002 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

웨스트 윌드 군단의 명령에 따라  
올로 호수와 그 인근 일대는 허가받지 않은 자의  
출입을 금한다.  
  
이 일대에서 위험한 야생동물이 목격되었다.  
그대 자신의 안전을 위해 지금 즉시 돌아가라.  
  
경계를 늦추지 말고, 적대적인 식물이나 동물과  
관련된 사건을 목격하면 즉시 가장 가까운  
군단 전초기지로 보고하라.
