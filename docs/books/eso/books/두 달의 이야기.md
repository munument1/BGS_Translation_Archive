# 두 달의 이야기

ID: ext-8a753a52b4366c0b8f47 / ESO 책 ID: 1511 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

하늘이 엘스웨어 위로 하얗게 내려앉고  
호수에 서리가 맺힐 때  
불길이 환하게 타오를 때  
늙은 뼈가 쑤시기 시작할 때  
  
그때 고양이들은 부디를 벗어 던지고  
모피가 추위를 막아 주며  
작은 달이 큰 달을 쫓아가  
그에게 오래된 비밀을 속삭이네  
  
허나 엘스웨어 위로 푸른 하늘 펼쳐지고  
강물이 빛으로 흐를 때  
불길이 잿더미 속에 사그라들 때  
젊음이 다시 날아오를 때  
  
그때 고양이들은 부디를 다시 두르고  
풍성하고 두툼한 갈기를 빗어 내리며  
큰 달이 작은 달을 쫓아가  
그녀를 사슬에서 풀어 주네
