# 영혼의 노래

ID: ext-244d59aede689ccbfb69 / ESO 책 ID: 403 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

밤은 어둡고,  
땅은 깊으니,  
그 온기가 너를 잠재워 두리라.  
  
네 아픔은 잊히고,  
네 고뇌는 사라지며,  
네 잠은 끝나지 않으리라.  
  
나는 너의 파수꾼,  
나는 너의 희망,  
나는 내 소임을 저버리지 않으리라.  
  
밤은 어둡고,  
땅은 깊으니,  
오늘 너는 일어나지 못하리라.
