# 허씬에게 올리는 기도

제 무기를 그대께 들어 올리나이다!  
축복을 내리시고, 올바른 길로 이끄소서—  
  
활이여!  
검이여!  
단검이여!  
발톱이여!  
  
사냥을 시작하게 하소서!  
피가 흩뿌려지게 하소서!  
사냥하는 자와 사냥당하는 자,  
죽음에 이르는 추격이 되게 하소서!
