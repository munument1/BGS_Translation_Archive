# 사랑의 영원한 화염

ID: ext-a1054626aec3f767820d / ESO 책 ID: 936 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

안코나스라 불린 화염 마법사,  
낮에는 위대한 스승이었으나,  
밤이면 욕정에 굴복하여,  
알란웨의 침상에 들었네  
  
그의 정신은 예리했고, 그의 불꽃은 밝게 타올랐으나  
제 스승을 그는 배신하였으니,  
그 살이 타오르매, 나는 기쁘도다,  
알란웨의 고통을 위하여
