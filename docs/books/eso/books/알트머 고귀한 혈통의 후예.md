# 알트머: 고귀한 혈통의 후예

ID: ext-b480a029ed5a5fcca5c3 / ESO 책 ID: 1307 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(스스로 자처하기를) 고대 알드머의 가장 순수한 혈통을 이어받은 알트머는 우아함과 세련됨과 힘의 제국을 일으켜 세웠다. 이 전시실에 놓인 여러 유물은 그들이 다다른 예술적 성취와 통치자로서 짊어진 무거운 책무를 함께 보여준다.
