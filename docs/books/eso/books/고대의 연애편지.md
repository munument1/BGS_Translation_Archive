# 고대의 연애편지

ID: ext-c20bc5d21746973e3822 / ESO 책 ID: 2092 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

내 가장 사랑하는 아코니아에게,  
  
칠흑 같은 이 밤 한가운데 홀로 선 채  
내 마음은 겨울 마름병처럼 시리기만 하오  
그대만이 오직 그대만이 나를  
저 햇살 아래로 돌이켜 줄 단 한 사람.  
  
파도는 부서져 해변에 흩어진대도  
내가 간절히 부르는 이는 오직 그대  
그대 따스한 품으로 나를 불러 주오  
시간과 거리를 넘어 내 달려가리니  
  
전쟁의 불길 속 마지막 잿불이 흔들리오  
부디 모든 것이 예전 그대로 돌아가기를  
내 다시는 배 띄워 떠나지 않으리니  
내 마음 그대 곁에 영원토록 머무르리.  
  
그대를 사랑하는,  
  
로가노  
백부장, 제33보병대, 제2군단
