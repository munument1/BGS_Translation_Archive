# 반다리의 방식

ID: ext-64d73bca1522f85f3f02 / ESO 책 ID: 1075 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

반다리의 또 다른 자식을 헐뜯지 말라.  
  
모든 거래에 빈틈없이 임하라.  
  
받은 선물은 그에 걸맞게 되갚으라.  
  
공정한 거래가 반드시 금화로만 공정할 필요는 없다.  
  
진실과 영리함이 굳이 적이 될 까닭은 없다.  
  
잃은 것을 찾고, 찾은 것을 거래하며, 쓸모없는 것은 그대로 두라.
