# 휘갈겨 쓴 메모, 암석 정원

ID: ext-70d9c9ff7e9f29a2be98 / ESO 책 ID: 6116 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

글룸스포어 균은 반응성이 매우 높음—완벽한 촉매  
비고: 포자를 방출하여 가능한 곳마다 배양할 것  
  
핏빛기사에게 먹임, 분쇄—결과 불확실  
실험체가 중독 증상을 보임  
대사 작용의 가능성?  
  
강제로 먹이니 사망(조수)  
실험체의 내성이 높음  
핏빛기사의 이코르 추출—희미하게 빛남—가설 확인  
  
말뚝버섯 확보, 대량으로; 먼저 샤우러스에게 시험할까?  
생리 구조의 문제? 늑대인간?     
비고: 소모용 뱀파이어 확보   
더 나은 방법: 뱀파이어 조수—소모용 뱀파이어를 만들 것
