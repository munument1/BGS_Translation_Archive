# 힐카의 심문 기록

ID: ext-f9f2f57f7f48bd4b21af / ESO 책 ID: 1735 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

밀정: 조약에게 버림받은 기분이 어떤가.  
  
힐카: 나를 버린 건 조약이 아니야. 트라고프지.  
  
밀정: 그자를 정말로 증오하는군, 그렇지 않나?  
  
힐카: 그자가 받아 마땅한 만큼일 뿐이야.  
  
밀정: 무슨 뜻이지?  
  
힐카: 카짓 하나를 문슈거 앞까지 데려가지도 못할 무능한 멍청이라는 뜻이야.  
  
밀정: 그럼 자네 휘하의 나머지는?  
  
힐카: 글쎄, 그자들이 똑똑했다면 우리가 지금 이 꼴로 여기 있겠어?
