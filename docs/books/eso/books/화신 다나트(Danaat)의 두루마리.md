# 화신 다나트(Danaat)의 두루마리

ID: ext-3d33b998df206ae23cf9 / ESO 책 ID: 4025 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

나의 이 슬픈 이야기가 가르치는 바는, 현명한 조언을 거부하는 자는 결코 네레바린이 될 수 없다는 것이니라.  
  
네레바린은 선언할 줄 아는 만큼 귀 기울일 줄도 알아야 한다. 나는 애쉬칸들과 지혜로운 여인들의 현명한 조언을 받아들이기를 거부하였고, 그것이 내 부족의 멸망과, 네레바르의 정신을 구현하려던 내 여정의 끝을 불러왔다.  
  
나는 내가 가장 잘 안다 여겼으나, 실은 아무것도 알지 못하였다. 그것은 네레바린의 길이 아니니라.
