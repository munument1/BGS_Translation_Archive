# 드루이드 왕의 의류 단서

ID: ext-f2b0217739f7c8ef98d6 / ESO 책 ID: 7546 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

갈렌과 그 담쟁이 둘러싼 집으로 배를 저어라  
땅이 끓어오르고 대지가 신음하는 곳으로  
  
혹 많은, 뿌리로 엮인 다리 아래에서  
빛나는 돌들이 얽혀 맺힌 고리를 찾아라  
  
갓 솟은 바위를 우아하게 밟으며  
금이 간 내 눈의 밑바닥으로 나아가라  
  
그대여, 그대의 카드가 여기 잠들어 있으니  
섬의 울부짖음에 귀를 기울여라
