# 누른힐데 여왕의 몰락

ID: ext-63d251881937e3a4d288 / ESO 책 ID: 392 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

소븐가르드의 영광을 노래하라! 누른힐데의 이야기를 노래하라!  
			오, 사랑스러운 여왕이여, 노드와 신들의 총애를 받은 이여,  
			그대는 아카비리에 맞서, 저 사악한 침략자들을 물리쳤도다,  
			그대의 고운 머리가 떨어졌을 때, 우리는 갓난아이처럼 울었으나,  
			우리는 아노라, 그대가 저 위 소븐가르드에서 우리를 굽어살피심을!  
			소븐가르드의 영광을 노래하라! 누른힐데의 이야기를 노래하라!  
			사랑하는 우리 여왕을 위해 울지어다!  
  
						— 윈드헬름의 음유시인, 헬그레이어 류트 보이스
