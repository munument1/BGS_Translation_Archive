# 그림자의 비늘

ID: ext-a90cf4305eb6c8103ebd / ESO 책 ID: 5360 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

니스우 제울름 지음  
  
어둠 속의 별들이여, 별자리여,  
우리가 거두어야 할 자들을 일러 다오  
필요한 무리에게 맡겨져  
필요한 길을 배우도록  
  
그림자의 비늘, 죽음의 손이여  
그대의 칼날로 시디스께 영광을  
필요한 변화를 빚어내고자  
흘려야 할 피로써  
  
어둠 형제단에 드는 그대여  
오직 하나의 거짓에 이끌려  
우리의 헛된 말을 기억하고  
헛된 눈으로 바라보라  
  
언젠가 그대의 주둥이가 창백해질 때  
그대는 늪으로 돌아가리니  
어둠은 그대의 가슴에 남으리라  
그대의 비늘은 아직도 그림자이기에
