# 단서: 세포라의 통찰

ID: ext-e82201c780f0a726197c / ESO 책 ID: 7256 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

아가리가 벌어져 울부짖네  
그 차디찬 항구에서.  
  
광막한 동굴 안에서  
밝은 창들이 대담히 솟네.  
  
드높이 쌓인 소울젬 사이  
밤보다 더 검게 물든 곳.  
  
여기 그대의 카드가 잠드니  
탑의 통찰이라.
