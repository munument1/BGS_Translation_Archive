# 북부의 진실

ID: ext-1304f4d49a4f4946491b / ESO 책 ID: 326 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

눈이 스러지고  
강물이 불어 넘칠 때  
태양은 한 송이 꽃처럼  
어린 소년의 모자 위에 앉는다.  
현명한 노드는 안다  
결코 오래가지 못하리란 것을.  
그는 그날을 누린다,  
비록 쏜살같이 흘러가더라도.  
  
눈이 사라지고  
강물이 메말라갈 때  
태양은 성난 눈동자처럼  
쨍쨍 내리쬔다.  
현명한 노드는 안다,  
날이 길지라도,  
바로 이날들이야말로,  
그가 건강하고 강건하여,  
싱그러운 봄 흙에서  
씨앗처럼 자라나는 때임을.  
  
서리가 돌아오고  
강물이 얼어붙을 때  
태양은 저녁 안개 아래  
하늘로 가라앉는다.  
현명한 노드는 안다  
제 힘이 시들지라도,  
이제는 헤아릴 때요,  
갈무리할 때임을.
