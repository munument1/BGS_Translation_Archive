# 솔스티스로 우리는 왔다

ID: ext-9a3de6df168d359118b9 / ESO 책 ID: 8530 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(쇼르의 주둔지의 홀과 선술집에서 아직도 불리는 하에프리딩의 뱃노래.)  
  
우리는 탐리엘 해안을 따라 항해했네,  
새 땅을, 새 해안을 찾아서,  
내키는 대로 약탈하고 노략질하며,  
아, 곳간 채우는 그 즐거움이란!  
  
하에프리드라는 종사의 인도를 받아,  
약탈에 빈틈이 없던 그이였지,  
허나 바람이 돌자 그녀의 노래도 바뀌어,  
우리 모두 일을 그르쳤다 하지 않겠나!  
  
이제 정착해 뿌리를 내릴 때,  
우리만의 땅이라 부를 곳을 찾자,  
장사는 흥하고 위험은 적으며,  
곡식 거둔 뒤 벌꿀술이 흐르는 곳을!  
  
솔스티스로 우리는 왔네,  
솔스티스에 우리는 닿았네,  
우리는 외쳤네, "저주 따위 꺼져라!"  
카인과 쇼르여 인도하소서, 우리는 노래했네!  
  
이제 우리에겐 우리만의 마을이 있고,  
그곳은 날씨가 온화하며,  
벌꿀술이 물처럼 흐르네,  
솔스티스로 우리는 왔네!  
솔스티스로 우리는 왔네!
