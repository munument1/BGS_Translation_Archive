# 재앙이여, 물러가라

ID: ext-932ab96984a6166cf896 / ESO 책 ID: 6684 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

대지가 흔들리고 하늘이 떨리며,  
숲은 불길에 휩싸인다.  
어둠이 내려앉고 혼돈이 번지며,  
배신이 나날을 가득 채운다.  
  
재앙아, 우리에게서 물러가라,  
지진은 우리 이웃에나 보내거라.  
죽음도 파괴도 우릴 비켜 지나가라,  
불과 홍수는 남의 챔버나 채워라.  
  
폭풍이 먼 구름 너머에서 몰아치고,  
화마가 타오르며 죽음이 쌓인다.  
어둠이 드리우고 불화가 다가오며,  
오블리비언의 관문이 활짝 열릴 때,  
배신이 검날처럼 번뜩인다.  
  
재앙아, 우리에게서 물러가라,  
지진은 우리 이웃에나 보내거라.  
죽음도 파괴도 우릴 비켜 지나가라,  
불과 홍수는 남의 챔버나 채워라.  
  
파괴의 주여, 재앙의 프린스여,  
우리 백성에게는 손을 거두어라.  
유혈의 신이여, 배신의 왕이여,  
네 불행은 다른 곳에나 가져가거라.
