# 망자를 찬미하는 대구시

ID: ext-99004e0f284681a56db4 / ESO 책 ID: 3001 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

페로도마스 지음  
  
살아 있는 그 어떤 아름다움도  
주검과 그 흐릿한 응시를 따르지 못하네  
  
숨을 거두고 떠나간 자들의  
육신을 바라보면 전율이 이는구나  
  
시신은 그대의 청을 거절하는 법이 없고  
차갑고 고요하니 내게 더없이 어울리네  
  
강령술이라는 이 로맨스를 떠올리기만 해도  
내 심장은 뛰놀며 춤추기 시작하네
