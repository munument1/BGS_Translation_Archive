# 두 달의 운율

ID: ext-d683cc050dcd129a6261 / ESO 책 ID: 3042 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

작은 달, 미소와도 같이,  
황금빛 자태로 저문다.  
  
작은 달, 금빛 쌍둥이,  
크고 활짝 핀 웃음을 두르고.  
  
높은 달, 당당한 달,  
하늘 더 높이 떠, 너무 일찍 저문다.  
  
밤하늘에 뜬 세 개의 달,  
참으로 진귀한 광경이로다.  
  
규칙을 따라 달을 놓으라,  
작고 고요한 웅덩이 곁에.  
  
높은 달, 미소 짓는 달, 그리고 금빛 쌍둥이,  
바로 놓으면 그대가 승부에서 이기리라.
