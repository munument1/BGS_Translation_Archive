# 해그레이븐 마트론 단서

ID: ext-79750336abc93dffe73a / ESO 책 ID: 7258 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

산봉우리 드높이 솟은 곳  
오시머의 옛 고향.  
  
적들이 발버둥치다 스러지는  
서리가 거세게 부서지는 곳.  
  
비틀린 오래된 나무 아래  
하피들이 깔깔대며 콧김을 내뿜는다.  
  
그대의 카드가 여기 잠들어 있으니  
해그레이븐의 반론이라.
