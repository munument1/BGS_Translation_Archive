# 작은 한 끼, 빠른 한 끼

ID: ext-87e04b9664b4fcb1a4b5 / ESO 책 ID: 353 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

광야를 누비는 자 지음  
  
토끼: 무척 빠르지만 맛이 좋다. 스튜로 끓이거나 푹 조리고, 귀는 마을에 내다 팔아라.  
  
까마귀: 씹는 맛이 일품! 늪지 암탉이 떠오른다. 밤포어로 양념하라.  
  
개: 아군 앞에서는 먹지 마라. 노드의 신성한 동물 가운데 하나라 그들의 노여움을 산다. 대신 애완동물로 기르도록.  
  
고양이: 맛이 좋다! 이 역시 아군 앞에서는 먹지 마라. 또 하나의 신성한 동물이다. 길거리에서 잡아오되 꼬리는 반드시 숨겨라.  
  
염소: 뿔만 빼고 전부. 뿔은 너무 질기다.  
  
부두 쥐: 담즙 맥주를 발라 굽는다. 맛이 좋다! 선원들에게서도 고맙다는 말을 듣게 될 게다!  
  
원숭이: 어찌나 귀여운지, 허나 누린내가 난다. 드래곤의 혀 수액을 바른 뒤 테일룰 럼을 발라 굽는다.
