# 구겨진 동요

ID: ext-d16d48c418f4aef37bea / ESO 책 ID: 5460 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

어느 벗이 지은, 덕을 향한 갈망  
  
달콤한 스렌다르의 요람이여,  
국자에는 국 한 술 없고,  
펄펄 끓일 차에 부을 물도 없네,  
  
웅덩이는 자꾸만 말라 가고,  
넋은 자꾸만 가라앉는데,  
영혼의 자비는 어디로 갔는가?  
  
쓰러져 죽어 가는 이들 위해,  
그들은 눈물 한 방울 흘리지 않았네,  
물이 산들바람처럼 흐르던 그때에,  
  
자비받을 자격 있는 건 오직 하나뿐,  
그러니 우리는 그녀에게 보답하리,  
역병을 이겨 낸 달콤한 고양이에게.
