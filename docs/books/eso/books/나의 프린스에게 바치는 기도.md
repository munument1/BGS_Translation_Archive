# 나의 프린스에게 바치는 기도

ID: ext-db4528600fd310decc24 / ESO 책 ID: 2473 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

이 제물은 보잘것없으나,  
부디 간청하나이다!  
  
저의 행동을 인도하시고,  
저의 생각에 귀 기울이소서  
세월을 가로질러, 그리고  
뭇 영역을 지나  
  
저는 제단으로 나아가나이다,  
제 마음은 가득하나이다   
헌신과 사랑으로  
나의 프린스를 위하여!
