# 서약식의 역사

ID: ext-39c1616efbcdd9afd583 / ESO 책 ID: 742 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

이빨과 발톱  
타오르는 피  
혼돈이 다스리고  
종족은 더럽혀졌네.  
  
잃어버린 이야기  
더러운 역사 속에  
잃어버린 세대  
늑대인간의 울음 속에.  
  
허나 어느 신의 자비와  
어느 영웅의 영혼이  
뒤틀린 형상과 맞서 싸웠네  
태고의 흙 위에서.  
  
대의는 스러진 듯하였고  
희망은 그토록 메말랐으나  
온통 녹색을 두른  
한 여인이 나타나기까지는.  
  
영웅과 레이디  
그리고 신, 오직 그들이  
맞서 싸웠네, 근육과  
피와 뼈로써.  
  
그리하여 종족은 구원받았네  
짐승 같은 분노로부터  
서약을 깨뜨린 자들은  
진창 속에 잠들도록 보내졌네  
  
영웅과 레이디  
영원토록 이어지리  
위대한 서약식으로  
하나로 맺어졌으니.
