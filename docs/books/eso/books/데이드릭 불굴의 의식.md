# 데이드릭 불굴의 의식

ID: ext-0e74ddc9ec25713074fe / ESO 책 ID: 2479 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

데이드릭 프린스의 권능으로, 헤아릴 수 없는 지혜를 내게 내리소서.  
  
끝없는 오블리비언의 너비와 깊이로, 상상조차 미치지 못할 기예를 내게 내리소서.  
  
몰라그 발의 피로 물든 철퇴로, 가늠할 수 없는 힘을 내게 내리소서.
