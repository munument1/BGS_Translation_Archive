# 정비 기록 5352

ID: ext-9d075e10cb4c9ecbff51 / ESO 책 ID: 4705 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

클락워크 시티 생물군에서 새로운 생명체의 급증 감지. 유지 관리 프로토콜 R4-91 개시. 야간 주기를 위한 온도 하강. 수질 오염 물질 3% 증가. 증류 개시 장치로의 투입 가속 권장. 갈바닉 엔진에 정류기 재보급 필요. 추가 작업량에 대응해 팩토텀 기능 증대. 정기 유지 관리를 위한 추가 팩토텀 권장. 소사 실 경에게 요청 발송.  
  
상태 보고: 불안정화 위험 있음.
