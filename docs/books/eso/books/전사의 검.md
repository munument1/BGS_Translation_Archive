# 전사의 검

ID: ext-2eb79fd670712448b159 / ESO 책 ID: 765 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

참회자여, 트리니막의 검은 언제나 그대 곁에 있느니라. 약탈자와 침략자에 맞서 우리 백성을 이끄신 분. 싸움의 한복판에서 도움과 위안을 베푸시는 분. 그분의 활력이 그대의 발걸음마다, 행함마다 깃들기를.  
  
이곳에서의 경배를 마치려거든, 이렇게 읊으라. "창공과 부동의 중심에 걸고, 나는 내 백성을 지킬 것을 맹세하노라. 트리니막의 검에 걸고 나는 맹세하며, 그분의 도움을 청하노라."
