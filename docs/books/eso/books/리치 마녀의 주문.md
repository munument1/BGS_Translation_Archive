# 리치 마녀의 주문

ID: ext-23dab3d82eb9b1ac753c / ESO 책 ID: 6362 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(롱하우스 황제들을 섬기는 황실 서기 바라나 타포가 구전을 받아 적다.)  
  
귀 기울이라, 피를 나눈 이들이여  
우리의 노랫소리를 들으라  
그림자가 길게 드리울 제  
우리에게 남은 때는 짧으니  
드넓은 눈을 뜨고  
강대한 영혼들이 기다리누나  
늑대의 송곳니는 날을 세운다  
무리를 구하기 위하여  
  
귀 기울이라, 위대한 야수여  
우리의 노랫소리를 들으라  
질긴 힘줄과  
팽팽한 근육으로  
우리를 통해 힘을 내리소서  
그리하면 우리의 영혼이  
흙 위로 쏟아지리니  
그대에게 바칠 보답으로  
  
귀 기울이라, 검은 파리여  
우리의 노랫소리를 들으라  
공허로 가득 찬  
우리의 굶주림을 알라  
부패의 활력과  
공허의 힘이  
영혼이며 갈망으로 찬  
우리의 가슴을 비우나니
