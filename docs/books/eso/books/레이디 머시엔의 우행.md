# 레이디 머시엔의 우행

ID: ext-c9f877b8280866695d13 / ESO 책 ID: 1879 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(작자 미상)  
  
마르시엔 부인은 정신이 좀 나갔지  
제가 드웨머인 줄로만 알았다네  
북쪽 능선에서 부둣가에 이르도록  
드워프 광석을 사방에 흩뿌렸네  
  
바퀴 달린 차축 위에다  
쉭쉭 김을 뿜는 찻주전자를 얹고는  
클래츠가에서 온 구조체라 우겼다네  
정말이라니까, 진짜라고 말이야  
  
놋쇠와 주석으로 연장 몇을 벼려  
"음향 설계자"에게 바치겠다며  
화로에 불을 지펴 그것들을 쑤셔 넣자  
집은 폭발해 산산이 부서졌네  
  
나선형 칼날을 꼭대기에 세운  
번쩍이는 놋쇠 판금 갑옷을 걸치고  
격자 틈에 소울젬을 끼워 넣더니  
펑! 하는 소리와 함께 사라져 버렸네!
