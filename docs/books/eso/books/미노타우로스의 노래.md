# 미노타우로스의 노래

ID: ext-e8dd068c988b55a142fa / ESO 책 ID: 3699 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

오 미노타우로스여, 오 미노타우로스여,  
분노에 찬, 비천하게 노려보는 짐승이여.  
오 미노타우로스여, 오 미노타우로스여,  
그대의 고귀한 풍채를 누구도 부정치 못하리라.  
  
그대는 제국의 폐허 곁에 모여드나니,  
발굽과 뿔을 지닌 영원한 수호자로다.  
어떤 기억이 그대를 그 길로 이끄는가,  
그대가 애도하는 것은 벨하르자인가, 아니면 제국인가?  
  
오 미노타우로스여, 오 미노타우로스여,  
그대는 괴물인가, 머인가, 인간인가?  
오 미노타우로스여, 오 미노타우로스여,  
그대가 어찌 신성의 계획에 깃들었는지 우리에게 일러다오!
