# 광부의 애가

ID: ext-401587b12cdd8f18ccab / ESO 책 ID: 1286 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

어둡고 어두운 광산에서 하루 종일,  
곡괭이를 거듭거듭 휘두른다.  
금속이 돌에 부딪치는 소리,  
우리는 고되게 일한다, 외로이 일한다.  
  
어둠 속에서 하루 종일 고생하며,  
다음 광맥이야말로 표식에 닿기를 바란다.  
가난한 자는 황금빛 광석을 꿈꾸고,  
우리 현장 감독은 고함친다, "더 파라!"  
  
나는 계속 파며 에잇 디바인께 기도한다,  
산 아래에서 죽는 것이 내 운명은 아니기를.  
나는 광부다, 좋든 싫든,  
피와 땀과 눈물은 내 지갑을 채워 주지 않는다.
