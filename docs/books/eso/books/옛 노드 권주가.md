# 옛 노드 권주가

ID: ext-cd259e3cb28ef9bcdc83 / ESO 책 ID: 6052 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

쉬어포인트 산을 올랐네,  
쟁여둔 벌꿀술을 홀짝이며.  
눈앞이 점점 흐릿해져,  
글자도 제대로 못 읽을 지경.  
  
따뜻하고 건조한 동굴을 찾았더랬지,  
경고 표시 하나 보이지 않았네.  
늙은 서리 트롤 곁에 웅크려 잠들었더니,  
아침이 오자 우리 둘 다 놀라고 말았네.  
  
벌꿀술, 벌꿀술, 벌꿀술, 벌꿀술!  
그것만 있으면 다른 건 필요 없네.  
달콤하고 독하니,  
이리 좋은 것이 나쁠 리 있나,  
벌꿀술, 벌꿀술, 벌꿀술, 벌꿀술!  
  
그 트롤에게 병 하나 건넸더니,  
단숨에 들이켰다네.  
내 주위를 즐겁게 춤추다가,  
막대기로 날 내리쳤지.  
  
몇 시간 뒤 깨어 보니,  
늙은 트롤은 코를 골고 있었네.  
내 벌꿀술을 죄다 마셔버렸지만,  
그래도 미워할 수가 없더군.  
  
벌꿀술, 벌꿀술, 벌꿀술, 벌꿀술!  
그것만 있으면 다른 건 필요 없네.  
달콤하고 독하니,  
이리 좋은 것이 나쁠 리 있나,  
벌꿀술, 벌꿀술, 벌꿀술, 벌꿀술!  
그것만 있으면 다른 건 필요 없네.  
달콤하고 독하니,  
이리 좋은 것이 나쁠 리 있나,  
벌꿀술, 벌꿀술, 벌꿀술!
