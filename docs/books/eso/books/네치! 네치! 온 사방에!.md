# 네치! 네치! 온 사방에!

익명의 저자  
  
네치! 네치! 사방에 가득!  
저 높은 곳에서 태어나,  
결코 내려오지 않는다네.  
  
네치! 네치! 사방에 가득!  
수컷도 암컷도 있고  
파란 놈도, 갈색 놈도.  
  
네치! 네치! 사방에 가득!  
축 늘어진 그 촉수는  
마치 실내복 같다네.  
  
네치! 네치! 사방에 가득!  
소리 하나 없이  
슬그머니 다가온다네.  
  
네치! 네치! 사방에 가득!  
숨어도 소용없으니,  
끝내 들키고 말리라.
