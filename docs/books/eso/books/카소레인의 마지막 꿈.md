# 카소레인의 마지막 꿈

ID: ext-3b5a6730eb30a4b7f67b / ESO 책 ID: 7365 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

한 그루 나무 위에서 세 알의 씨앗을 보았네  
로완과 물푸레와 참나무의 씨앗을.  
정성껏 그것들을 흙 속에 심었네  
우리 백성을 인도하고 가르치고자.  
  
세 그루 나무, 아홉 가지, 오백 잎  
뿌리마다 한 계절씩.  
씨앗마다 깊은 잠에 들게 하라  
그러면 왕좌가 새로워지리니.  
  
산이 흔들리고 씨 뿌리는 자가 깨어나면  
왕좌는 다시 꽃피우리라.  
하나의 선택, 하나의 의지, 하나의 묶는 말이  
모든 땅을 축복하거나 짓벌하리라.  
  
머나먼 계절의 끝에 날이 오리니  
씨 뿌리는 자를 또렷이 깨우는 날이.  
기꺼이 바치면 만사가 좋으나  
빼앗으면 재앙이 찾아오리라.
