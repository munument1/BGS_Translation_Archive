# 늑대 소년 웰기탈

ID: ext-ec008d51fd461bbf96dc / ESO 책 ID: 1486 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

에두아르 롱탕의 작으로 전해짐  
  
키나레스는 비와 구름과 하늘에서 지켜보셨다  
털가죽 변장에 몸을 감춘 브레튼 아이를  
글렌움브라 골짜기의 늑대들이 그를 기르니  
늑대 소년은 숲과 언덕과 습지를 스캠퍼하였다  
사냥감의 살점으로 이를 갈고 단련하며  
근육과 뼈가 자라 더는 꼬맹이가 아니었다  
밤이면 세쿤다의 빛 아래 사냥감을 쫓고  
무리는 더욱 대담한을 키워 먹이를 찾고 약탈하였다  
  
펠의 여정 농부들의 머리칼이 곤두섰으니  
어른거리는 어두운 형체, 그것은 폭력의 흉조였다  
소들을 쓰러뜨리는 굶주린 으르렁 소리  
늑대를 노예로 부리는 포식자 아이  
모피를 바라며 사냥꾼들이 파견되었다  
늑대들은 달아나 가시줄기 속에 숨었다  
늑대 습격은 더욱 대담한을 더해 마을을 침범하니  
장로들은 무리를 쓸어버릴 계획을 세웠다  
  
묶인 염소가 울부짖는다, 미끼로 삼으려 놓은 것  
늑대 소년과 무리를 끔찍한 운명으로 유인하였다  
무리는 먹이에게 달려들었다, 한 끼를 노리며  
그러나 펠의 여정의 궁수들이 곧 그들을 제압하였다  
화살이 빠르게 날아가고 소년의 두건이 벗겨졌다  
피로 물들고 화살에 꿰뚫려 그는 울음 소리와 함께 쓰러졌다  
늑대 소년 베르기탈은 황야에서 불태워졌다  
키나레스 품으로 돌아가라 — 이제 그대의 영혼은 정갈하다
