# 피의 연도 완수

ID: ext-344dea7bc45f50678e4f / ESO 책 ID: 3517 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

그대에게 바칠 먹잇감이니, 드래드 마더여, 아누의 자손들을.  
  
우리에게서 받으소서, 밤의 어머니여, 그대의 자손들을.  
  
저주가 감추려 했던 자들을 내 바치나이다.  
  
그 눈을 보면 그들을 알아보리라.  
  
찬미하라, 그들이 피 속에서 눈물 흘리니.
