# 에바노아 하클린

ID: ext-87ef62999bf26c74f68a / ESO 책 ID: 7937 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

채석공 중의 채석공  
  
고된 일을 마다한 적이 없었다  
  
온투스에서 가장 빠른 곡괭이로 이름났다  
  
그 망할 열병에 너무 젊은 나이로 떠났다  
  
친구들과 사랑하는 이들,  
그리고 스트리드강만큼이나 긴 빚을  
스톤칩 도박장에 남기고 떠났다
