# 도르조그 거터 킹의 발라드

ID: ext-2aa38ae5ae0d81e65157 / ESO 책 ID: 2721 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

음유시인 지망생 셰이-비쿠스 지음  
  
그는 성 한 채 가진 적 없었으나  
언제나 왕관을 머리에 썼고  
스키버도 소매치기도 똑같이 사랑하였다  
군림한 적 없었으되 언제나 의롭게 다스렸으며  
믿음직한 기사 열둘을 곁에 거느리고  
투기장에 들어 온갖 역경을 무릅쓰고 승리하였으니  
도르조그 거터 킹의 전설이 사방으로 널리 퍼졌더라.
