# 하늘-이야기꾼

ID: ext-cf4725ec3abda37f399a / ESO 책 ID: 5910 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

이 북은 섀도우펜에서 수없이 일어난 노예 반란 가운데 한 사건에서, 이름 모를 아르고니안 노예가 사용한 것이다. 주인의 이름은 역사 속에 잊혔으나, 구전에 따르면 하늘-이야기꾼이라 불린 이 북은 봉기가 한창일 때 여러 노예 무리에게 전갈을 보내는 데 쓰였다고 한다. "북의 목소리"는 흔히 반란군에게 위대한 위업을 떨치도록 북돋운 것으로 전해진다.  
  
이 북은 모든 음유시인에게, 가장 혹독한 시절에도 음악이 기상을 드높이고 영혼을 일깨울 수 있음을 일깨워 주는 증표다.
