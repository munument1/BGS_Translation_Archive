# 길 잃은 자의 비탄

ID: ext-4e4c9af40a10a1010505 / ESO 책 ID: 746 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

작자 미상  
  
넌을 탐험하라 하였다.  
수많은 땅을 떠돌았으나  
고향이라 느낀 곳은 없었다.  
  
어느 상인 밑에서 일하며  
푼돈에 먼지 낀 가게를 쓸었다.  
존중도, 재물도 없었다.  
  
어느 부대에 들었다.  
우리는 전쟁의 공포를 보았다.  
피로 물든 전장을.  
  
화살 하나에 쓰러졌다.  
탐욕 탓에 홀로 죽어  
낯선 자들의 손에 묻혔다.
