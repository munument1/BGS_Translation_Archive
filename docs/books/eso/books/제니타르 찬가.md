# 제니타르 찬가

성스러운 앤빌 앞에 무릎 꿇으라, 대장간 불꽃의 경건한 자식이여  
정직한 노고의 결실을 거두어, 제니타르께 그대의 사랑을 외치라  
  
제니타르여, 나의 노동의 주여  
내 두 손이 굳은살로 축복받기를 비나이다  
그대의 앤빌에 내 땀방울이 떨어지나니  
굳건한 심장이 내 가슴에서 고동치듯이  
  
제니타르여, 나의 부의 신이여  
내 보관함을 땀 흘려 번 골드로 채워주소서  
정직한 노역의 결실로  
지킨 맹세와 정직히 판 좋은 물건으로  
  
제니타르여, 나의 안식의 아버지여  
내 허리에 마땅한 평안을 내려주소서  
날이 저물고 숯불이 사위어갈 때  
갈증을 풀어주시고 노고를 거두게 하소서
