# 하인드쿼터스 숙박부

ID: ext-77b6fbfe3582d7887478 / ESO 책 ID: 1740 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

기록 1  
— 카짓 설탕 상인이 경비병과 함께 체크인.  
  
기록 2  
— 하이 엘프 순례자가 체크아웃.  
  
기록 3  
— 마오머 선원 일행이 체크인.  
— 모든 침상이 가득 참. 빈자리 없음.  
  
기록 4  
— 카짓 상인과 경비병이 체크아웃. 마오머들에게 ''권유''받아 그리하였다고 주장.  
— 상인이 떠난 직후 마오머 선원 둘이 곧바로 체크인.  
— 모든 침상이 가득 참. 빈자리 없음.  
  
기록 5  
— 마오머 일행 전원 체크아웃. 마지막 주 숙박비 지불을 거부했다! <<1>> 대사에게 청구서를 보내야겠다.
