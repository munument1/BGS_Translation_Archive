# 권리를 잃은 자들에게 바치는 송가

ID: ext-02b1cda9a8cd03ac640f / ESO 책 ID: 6751 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

우리는 언제나 왕관을 따르노라  
우리가 지키는 협약을 위하여.  
우리의 말들이 여기서 무너졌고,  
한 군대가 최후를 맞았다.  
  
다음번엔 머리를 쓰리라,  
그리하여 지도를 핏빛으로 물들이리라.  
  
The Disenfranchised(권리를 빼앗긴 자들)
