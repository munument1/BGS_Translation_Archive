# 에스란도라에게 바치는 송가

오 에스란도라여,  
그대를 흠모하나니  
  
그토록 붉은 머릿결  
그대 머리에 어여뻐라  
  
그대 미소 달콤하니  
가장 단 구아 고기 같아라  
  
오 에스란도라여,  
내 마음은 그대의 것  
  
그대 두 눈의 눈길에  
나는 한숨으로 가득 차고  
  
그대 까르르 웃는 소리에  
내 심장은 들썩이나니  
  
오 에스란도라여,  
그대의 광채에 잠기게 해주오  
  
그대의 브렐란
