# 절도의 관례 노래

ID: ext-0fde54e7c39f25c7682d / ESO 책 ID: 8138 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

먼저 내가 네 단검을 훔쳤고,  
네가 도로 훔쳐갔지.  
이제 네 단궁이 탐나는구나,  
네 봇짐까지 한꺼번에!  
  
순순히 넘겨다오,  
괜히 소란 피울 것 없다.  
돌고 돌아 오가는 법이지  
우리 둘 사이에서!  
  
이것이 도둑질 의식,  
보스머의 신성한 춤이라네.  
살금살금 슬쩍슬쩍 주고받으니,  
어찌나 낭만적인지!  
  
먼저 네가 내게서 훔치고,  
그다음 내가 네게서 훔치지.  
허나 우리가 저들에게서 훔치면,  
푸짐한 횡재가 따른다네!  
  
네가 내 금화 주머니를 가져갔구나,  
선뜻 나눠줬을 것을.  
헌데 거기 보이는 저게 무엇이냐?  
오 이런, 훔칠 거리가 눈에 띄는걸!  
  
이것이 도둑질 의식,  
보스머의 신성한 춤이라네.  
스르륵 잽싸게 주고받으니,  
어찌나 낭만적인지!
