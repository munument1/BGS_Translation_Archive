# 첨탑이 무너졌을 때

ID: ext-bc7b53af12ca1309f941 / ESO 책 ID: 6589 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

천둥이 울리고 하늘이 크게 갈라졌네  
야수가 나타나 악귀들을 이끌고 왔네  
사원이 서 있던 자리에 구멍을 뚫었건만  
우리는 끝내 무릎을 꿇지 않았네  
  
폭풍은 머리 위로 계속 소용돌이치고  
야수는 밖을 어슬렁거리지만  
내가 비참한 첨탑에 남아 있는 한  
희망의 불씨를 꺼뜨리지 않으리  
  
쾅 소리와 비명이 내리쳤네  
먼지 구름이 폐를 가득 채웠네

고개를 숙이고 입을 다물라

이 마을이 투쟁으로부터 지켜줄지라도  
우리가 얼마나 버틸 수 있을지는 아무도 모르나니  
삶의 벼랑 끝에 서서

어떤 서적에도 답은 없다  
추방자들 모두 데이건의 눈을 피해 숨어  
집으로 돌아갈 길을 찾기를 기도한다
