# 강대한 절도 단서

ID: ext-daa5d25e795ee7c37120 / ESO 책 ID: 7295 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

그랏우드에서 그대는 찾으리  
참으로 기이한 자리 하나를.  
  
눈에 멀어 길을 잃으리  
엉뚱한 곳에 놓인 팔리네스티.  
  
얼음 터널을 따라 내려가니  
태양은 시야에서 사라지고.  
  
여기 그대의 카드가 잠드나니  
도둑의 한 입이로다.
