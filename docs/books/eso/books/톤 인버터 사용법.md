# 톤 인버터 사용법

ID: ext-5e70bf4ca79900088034 / ESO 책 ID: 4043 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

1. 톤 인버터를 작동시키려면 자발적으로 동의한 성인 두 명이 필요하다. 조화로운 변조자 1명이 음파를 생성하고 준비하며, 공명 음조자 1명이 준비된 음파를 방출하여 소사 실의 개조된 에너지 흡수 장치를 방해한다.  
  
2. 조화로운 변조자는 전투 근처에서, 그러나 직접 전투에 참여하지 않은 상태로 톤 인버터를 조작하고, 공명 음조자는 장치를 소지한 적과 전투에 임한다.  
  
3. 조화로운 변조자는 톤 인버터를 조작하여 음향 에너지의 파동을 쌓아올린다.  
  
4. 톤 인버터가 적절한 리치에 달하면, 조화로운 변조자는 장치가 방출 준비가 되었음을 알린다. 예를 들어, 조화로운 변조자는 '준비됐다!'라고 외쳐도 좋다.  
  
5. 공명 음조자는 전투 중 잠시 멈출 틈을 만들어 톤 인버터를 방출한다. 주의: 시야가 확보된 어느 위치에서든 가능하다. 톤 인버터는 원거리에서도 공명 음조자를 인식하고 따르도록 설정되어 있다.  
  
6. 톤 인버터는 소사 실의 개조 장치에서 방출되는 에너지를 일시적으로 방해하는 방출을 내보낸다. 해당 장치를 소지한 자는 제한된 시간 동안 공격에 취약해진다.  
  
마지막으로: 소사 실의 장치를 소지한 자가 이미 흡수한 에너지의 양에 따라, 방해 효과와 그로 인한 허약함이 짧은 시간에 그치므로 이 절차를 여러 차례 반복해야 할 수도 있다. 꾸준히 임하면 만사가 잘 풀릴 것이다. 위대한 기어가 그대 곁에서 자유로이 윙윙거리며 돌아가기를!
