# 사랑하는 쿠드-나칼에게

ID: ext-179e1288f9b9518d8da2 / ESO 책 ID: 5271 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

그대는 물속을 휘젓고  
나는 저 높은 곳에서 지켜보네  
릴모스는 내 아래에서 숨을 쉬건만  
내 눈은 오직 그대만을 좇네  
  
남서쪽 하늘이 손짓하고  
느릿느릿 흔들리는 그대의 꼬리도 손짓하네  
그대는 두 손으로 물을 가르고  
내 두 손은 그대를 위해 토템을 새기네  
  
모든 것이 변해가도  
내게 변치 않는 단 하나는  
그대의 알을 품고픈 바람뿐  
  
-찰마트
