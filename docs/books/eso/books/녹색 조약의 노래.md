# 녹색 조약의 노래

ID: ext-130793d9988c091ba192 / ESO 책 ID: 8110 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

우리의 뿌리 깊은 곳, 아득한 옛날에  
이프레는 눈 아래 우드엘프들을 굽어보았고  
푸른 숲속에서 계약이 맺어졌으니  
이프레는 고요한 삶을 약속하였다  
  
"초록을 지켜라" 이프레가 힘차게 말씀하셨고  
그리하여 우리는 꽃과 나무를 모두 돌보았다  
"그러면 그곳이 너희의 진정한 고향이 되리라"  
그래서 밭을 갈고 씨를 뿌리고 거두는 일은 버려졌다  
  
여기 초록 안에선, 모든 식물이 살아가고  
잎과 꽃잎, 새 봉오리가 무성히 자라나니  
우리는 화살을 겨누어 먹을 것을 사냥하고  
쉬어야 할 때면 이프레께서 베풀어 주신다  
  
나무를 찍거나 조각하거나 베는 일은 없으니  
초록이 우리의 집을 견고하고 바르게 길러 준다  
나무에서 빼앗을 필요가 없거니와  
녹색 조약이 우리의 필요를 채워 주리라  
  
숲에 들 때면 부디 조심하라  
이프레의 친구들이 나무 곳곳에 있으니  
우리 같은 우드엘프들은 두려움이 없나니  
우리가 소중히 지켜 온 녹색 조약 덕분이로다
