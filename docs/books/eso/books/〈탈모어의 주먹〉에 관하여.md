# 〈탈모어의 주먹〉에 관하여

ID: ext-1cf8edc3c8d413035467 / ESO 책 ID: 1962 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

기밀 외교 전언: 탈모어 요원 전용  
  
수신인 한정: 알리노어 수정 탑, 교화의 새피아크 아이캔타  
  
현명하신 각하,  
  
돌이켜보면, 준군사 부대에 '탈모어의 주먹'이라는 칭호를 붙인 것은 명명법상의 오류였다고 생각합니다. 해당 부대의 기능을 정확히 표현한 칭호이기는 하나, 현지 토착어에서는 단순히 '탈모어'로 줄여 불리는 바람에 우리 외교단이 자치령 군용 조직과 잘못 동일시되고 있습니다. 게다가 탈모어의 주먹이 집행 임무를 수행하는 과정에서 일부가 필요하다고 판단하는 것 이상의 위력을 행사하는 경우가 있는 만큼, 이것이 우리 요원들이 거칠고 난폭한 폭한이라는 인식을 탈모어에 덧씌우고 있습니다. 말할 것도 없이, 현지 토착민들에게 협조를 구하는 협상에서 결코 유리하게 작용하지 않습니다.  
  
앞으로는 우리 집행 부대를 다시 '저스티시어'라 부르는 것이 현명하리라 생각합니다. 이름이 너무 딱딱하게 들린다는 이유로 카짓 시민들이 입대를 꺼리더라도 말입니다.  
  
외교의 동지로서,  
  
규범행정관 팔두일
