# 조심하라!

ID: ext-71850303299da2d16a44 / ESO 책 ID: 2516 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

언덕을 오르고,  
빗장을 풀어라.  
그 안에서 보게 되리니  
진귀한 물건이 가득하리라!  
  
윙윙대고 쉭쉭대며  
찍찍대는 소리 요란하구나.  
네가 찾은 것은 쥐 떼인가,  
아니면 톱니바퀴인가?  
  
이 소란스러운 곳에서는  
물건을 다룰 때 조심할 일이라,  
행여 드웨머가 잠에서 깨어  
너를 호되게 뒤쫓지 않도록!
