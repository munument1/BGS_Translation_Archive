# 바스티르 어부의 노래

ID: ext-3980e8d2991ae2ef9bb2 / ESO 책 ID: 7416 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

어기여차, 어기여차  
해안이 보일 때까지,  
밤이 지나 아침이 오도록  
그물이 다 해지도록.  
  
한번 먹잇감을 발견하면  
그날을 넘기지 못하지,  
우리 눈을 벗어날 순 없으니  
곧 한입 고리가 걸려들 테지.  
  
그때부터 겨루기가 시작되네  
배가 흔들리고 빙빙 돌아도,  
갈고리와 그물과 작살로  
사냥감을 가까이 끌어당기네.  
  
어기여차, 어기여차  
해안이 보일 때까지,  
밤이 지나 아침이 오도록  
고기를 낚으며 뿔피리를 부네.  
  
선창에선 그 시선들이 좋다네  
사람들이 우리 잡이를 우러르는,  
어찌나 큰 놈을 잡았는지  
다들 덩실덩실 춤을 추겠지.  
  
그렇게 하루를 마치고  
춤추며 흥겹게 노네,  
달콤한 벌꿀술 한 잔에  
두 발 쭉 뻗고 쉬어 가네.  
  
어기여차, 어기여차  
다시 닻을 올릴 때까지,  
우리는 마음껏 살아가며  
드넓은 공해로 나아가네.  
노래와 농담으로 돛을 올리니  
그것이 바로 바스티르 어부의 삶이라네!
