# 클라리스에게—내 연인이 되어줘!

ID: ext-eecba2393d8faf8b67a9 / ESO 책 ID: 1251 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

어디를 보든, 나의 사랑스러운 클라리스여,  
나는 그대를 생각하오. 한 무리의 기러기 떼,  
하늘 높이 떠오른 우뚝한 구름은,  
그대의 갈색빛 눈을 떠오르게 하오.  
숲속에서 새끼사슴을 마주칠 때면,  
그대의 황갈색 머릿결을 헤아리오.  
일리악을 가로질러 나는 항해하며  
일렁이는 물결마다 어김없이  
물결 아래에서도, 또 위에서도 그대를 보오—  
오, 술집의 클라리스여, 부디 내 사랑이 되어 주오!  
  
서명,  
  
조르주 플루프, 일등 항해사 (알아채셨소?)
