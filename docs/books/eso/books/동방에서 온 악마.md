# 동방에서 온 악마

ID: ext-da55a13e99aaedbbe228 / ESO 책 ID: 5813 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

왕국들은 모래 위로 뻗어 나가고  
평화가 기쁨에 찬 우리 땅을 덥히네,  
어둠을 꿰뚫어 빛나는 마음 하나  
시간의 실에 감싸여.  
   
악마 하나 동쪽에서 일어서고  
진홍색 야수 그 뒤를 따르네,  
오, 대지는 찢기고 그을렸으며  
백성들은 두려움만을 아는구나.  
   
전사 하나 검을 태양으로 쳐들고  
따르라 전사들을 불러 모으며,  
알코시가 아직 풀리지 않은 실을 이끄니  
그의 용사가 나아가누나.  
   
낯선 해안에서 병사들이 건너와  
우리의 공포의스런 전쟁에 합류하고,  
전사 곁에서 발걸음을 맞추며  
싸움을 준비하노라.  
   
진홍색 야수 기꺼이 하사하노니  
그 흉악한 적을 물리칠 뿔피리를,  
그 울림에 악귀들이 쓰러지고  
승리가 아주 가까이 보이는구나.  
   
전사는 최후의 항전을 펼치네  
두려운 악마를 맞서,  
얼음과 피가 평화로운 모래를 물들이고  
밤이 하늘을 가득 채우누나.  
  
쇠사슬과 주문이 악마를 단단히 결박하고  
어둠 속에 가두어 버리니,  
병사들은 새벽빛 속에서 승리를 기리고  
다시금 평화가 깃드노라.
