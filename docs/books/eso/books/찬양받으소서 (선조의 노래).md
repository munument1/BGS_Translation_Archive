# 찬양받으소서 (선조의 노래)

ID: ext-e900910a565463e2ccb2 / ESO 책 ID: 4895 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(음악: 신중하고 위풍당당하게)  
  
이제 마라를 찬양하세  
오, 사랑의 여신이시여  
저희에게 자식의 복을 내리소서  
높은 곳의 어머니시여  
  
합창  
손뼉 치며 찬양하라  
디바인들을 드높여라!  
손뼉 치며 찬양하라  
우리 조상의 핏줄을!  
  
이제 작세스를 찬양하세  
우리의 이야기를 기록하시는 분  
그 필경사께 영예 있으라  
영광의 서기시여  
  
합창  
  
이제 이프레를 찬양하세  
오, 첫 번째 엘노페이시여  
숲의 신이시여  
대지의 뼈가 길을 일러 주셨네  
  
합창  
  
끝으로 아우리엘을 찬양하세  
만물의 시조이시여  
당신을 닮도록 우리를 빚으셨으니  
현명하고, 고귀하고, 늠름하게  
  
합창
