# 훼손된 메이지 길드 보상 공고문

ID: ext-3b5927b75fe6219f19db / ESO 책 ID: 2435 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

공고:   
  
므탄즈 유적에서 회수한 드워프 부품에 두둑한 보상을 지급함. 메이지 길드 소속 멜라니온의 연구용임.  
  
[이 공고문은 "멜라니온"이라 적힌 하이 엘프를 그린 음란한 낙서로 훼손되어 있다. 그림 아래에는 이렇게 휘갈겨져 있다:]  
  
거짓말쟁이에 사기꾼 같으니! 드워프 톱니바퀴를 여섯 개나 갖다줬는데 받은 거라곤 형편없는 책 한 권이 다였다. 그것도 이미 읽은 책이었고.
