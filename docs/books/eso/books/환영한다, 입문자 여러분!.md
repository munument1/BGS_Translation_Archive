# 환영한다, 입문자 여러분!

ID: ext-97cafd9850465ecc5af1 / ESO 책 ID: 7286 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

어서 오게, 어센던트 입문자들이여!  
  
올-플래그 소도에서의 사건 이후, 우리가 패배했다 믿는 자가 많다. 허나 우리 이상의 화염은 그리 쉽게 꺼지지 않는 법. 그대들은 소문과 속삭임을 좇아 우리를 찾아왔다. 머지않아 다른 이들도 우리 땅을 다스리는 왕족 전쟁광들에 맞서, 점점 거세지는 저항의 물결에 합류하리라.  
  
시스트레스에 봉기가 다가오고 있다. 갈렌에서 벌어진 일은 시작에 불과하다. 드루이드 형제자매들과 함께, 마땅히 우리 것인 것을 되찾으라! 카소레인의 꿈은 반드시 이루어지리니, 우리는 힘을 모아 브레튼의 유산을 되찾을 것이다!  
  
내 약속하마,  
어센던트 로드
