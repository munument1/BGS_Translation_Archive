# 이곳은 통행 금지

ID: ext-b82239c84fd3fd3ce76f / ESO 책 ID: 884 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

거인의 분쇄(Giant's Crush)를 지름길로 쓰지 마라. 사랑하는 가족이 어쩌다 그리 부주의하게 거인에게 머리가 으스러졌는지 유족에게 설명하는 편지를 쓰는 것도 이젠 진절머리가 난다. 그냥 산을 빙 돌아가라. 운동 삼아 다들 좀 걷자고.
