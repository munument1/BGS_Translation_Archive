# 내가 구애하러 갈 때면

ID: ext-c18d623640d934ac100b / ESO 책 ID: 800 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

내가 구애하러 나설 때면  
숀헬름의 모든 하녀에게  
실크를 한 수레 가득 싣고  
땋은 머리에 맬 리본을 가져가리.  
  
그리하여 그는 온 세계를 떠돌았네  
제 신부를 찾아 헤매며  
허나 아카토시는 그를 내쫓았으니  
그 자긍심을 벌하기 위함이라.  
  
영광을 안기리라던 한 왕관  
허나 그들에게 보인 것은 피와 죽음뿐  
영광을 안기리라던 한 왕관  
랜서의 어리석음 탓에, 스러지고 말았네.
