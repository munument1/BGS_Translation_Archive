# 멸망과 어둠을 넘어

ID: ext-4706cbce5646d5aa0dc1 / ESO 책 ID: 5731 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

선택받은 전사는 확실한 죽음 앞에서도 두려움이 없어야 한다.  
마음에 어둠이 깃들도록 허락해서는 안 된다.   
  
삶을 소중히 여기지 않기에 죽음을 두려워하지 않는 것은 쉬운 일이다.  
그것은 어둠의 기만이다.  
  
선택받은 전사는 가슴속에 타오르는 화염을 부채질하니,  
그 마음은 삶과 사랑으로 환히 빛난다.   
  
그들은 싸워야만 하기에 싸운다,  
자신의 삶과 타인의 삶을 지키기 위하여.  
  
이를 알라, 그렇지 않으면 그대는 가면을 쓰지 못하리라.
