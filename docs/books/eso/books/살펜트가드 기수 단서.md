# 살펜트가드 기수 단서

ID: ext-63232a1cc8b894e5aec0 / ESO 책 ID: 7259 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

초록빛 그림자 드리우고  
파도가 출렁이다 부서질 때.  
  
바다 엘프의 칼날 번뜩이고  
스르르 기는 뱀들 사이에서.  
  
넓게 펼쳐진 가지 아래  
낮이든 밤이든.  
  
여기 그대의 카드가 잠드니  
바다뱀의 한 입이라.
