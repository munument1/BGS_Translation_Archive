# 네레이드의 딜레마

ID: ext-a95af3d956264ab610da / ESO 책 ID: 1851 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

안실 모비르 지음  
  
자, 한번 헤아려 보시게   
사랑을 빼앗긴 네레이드의 처지를  
네레이드란 어김없이 모두가  
여인일 뿐, 사내라곤 없다네  
사랑이 깃들 틈은 가늘기만 하니  
성이 하나뿐인 종족이 그렇다네  
사랑의 유희를 향한   
내 천성을 헤아려 본다면  
임 없는 네레이드로 사느니  
차라리 숲속의 암사슴이 되겠노라!
