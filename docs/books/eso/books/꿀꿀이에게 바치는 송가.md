# 꿀꿀이에게 바치는 송가

ID: ext-8caf8a7561d297bf50cb / ESO 책 ID: 349 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

리트렉 저  
  
분홍 돼지 친구들아!  
꿀꿀 꽥꽥 울며 땅을 파렴.  
오늘 하루도 힘껏 애써 보렴.  
내일이면 내 뱃속에 들어와 있을 테니.  
  
어찌 그리도 맛이 좋으냐, 돼지 친구들아?  
어머니의 냄비는 어떻게 너희를 탈바꿈시키는 걸까?  
어느 날엔 흙냄새를 풍기더니,  
그 다음 날엔 소븐가르드의 들판 같은 향이 나는구나.  
  
언제까지나 변치 말아라, 돼지 친구들아.  
누이들이 변해 가며 우쭐대도,  
어머니들이 잔소리하며 닦달해도,  
아버지들이 끙끙대며 투덜대도,  
너희만은 지금 그대로 남아 있어라.  
맛있는 채로.
