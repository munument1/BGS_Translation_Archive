# 휘갈겨 쓴 주문

ID: ext-f49f771938b3bd350dcf / ESO 책 ID: 6498 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

어머니의 슬픔을 깊이 들여다보고 분노의 씨앗을 뽑아내라,  
  
쓰라린 유령들을 불러내 영혼의 길을 밝히는 빛이 되게 하라,  
  
길고 비틀린 그림자로 피로 잃은 생명을 되살려라.  
  
살인이 앗아간 것을 되돌려라. 어떤 대가도 비싸지 않으리라.
