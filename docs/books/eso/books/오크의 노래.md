# 오크의 노래

ID: ext-fae5a3f1c4fb53f7bbc3 / ESO 책 ID: 393 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(벌꿀술을 마신다. 노래한다.)  
  
우린 오시머가 싫어! 우린 오시머가 싫어!  
냄새나고, 구리고, 정말이지 악취가 진동하지,  
눈밭에서 제 엉덩짝도 못 찾는 놈들이라네!  
  
우린 오시머가 싫어! 정말, 정말로 싫다네!  
수염도 없고, 머릿속도 텅 비었지,  
칼을 쥐여줘도 호커 한 마리 못 잡는 놈들이라네!  
  
(벌꿀술을 더 마신다. 다시 부른다.)
