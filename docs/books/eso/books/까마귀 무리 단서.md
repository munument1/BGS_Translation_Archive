# 까마귀 무리 단서

ID: ext-3a8b77d1963dc49567b9 / ESO 책 ID: 7251 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

펜스는 그토록 축축하고  
해그는 그토록 가까우니.  
  
유적은 가라앉았네  
브레튼의 눈물 한가운데.  
  
쓰러진 나무 한 그루가  
길을 가리키리라.  
  
여기 그대의 카드가 잠드니  
새 떼가 먹잇감을 노리는 그곳에.
