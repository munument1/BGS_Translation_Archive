# 절벽 보행자의 노래

ID: ext-266ea67cd1449667b877 / ESO 책 ID: 3999 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

클리프 레이서가 날개를 활짝 펼치고,  
하등한 새들이 경외하며 무릎을 꿇는 동안,  
너는 으르렁대고, 쉭쉭거리며, 침을 뱉고, 스크리치를 내지른다!  
나는 구아들이 서로 투덜대는 소리를 듣는다,  
"이 얼마나 무서운가! 이 얼마나 야만스런 울부짖음인가!"  
오, 너처럼 될 수 있다면.  
  
조금만 건드려도 네 성깔이 활활 타오르고,  
유리 구아를 낚아채 맹공을 퍼붓고 울타리를 쑥대밭으로 만들지!  
유리 로프트에 둥지를 틀고, 벽에 똥을 뿌려 대며,  
한여름 돌풍처럼 유리 지붕을 갈기갈기 찢어 놓고,  
유리 아이들을 겁주고 갓난아이들을 울음바다에 빠뜨리지,  
절대 변하지 않겠다고 약속해 다오.  
  
클리프 보행자여, 높이높이 내달려라,  
불타는 크랙스 위에서, 하늘에 닿아라!  
클리프 보행자여, 높이높이 내달려라,  
우레처럼 스크리치를 내질러라, 결코 죽지 말지어다!  
  
너는 내 장모처럼 앙심 깊고 하찮으며,  
모이주머니에 오래된 물고기를 쑤셔 넣은 듯 고약하지,  
너의 괴성은 유리를 깨고, 내 귀를 쨍하게 만드네,  
너의 썩은 무화과 냄새는 다 큰 머도 눈물 흘리게 하고,  
유리 베개에 오줌을 싸 놓으니 그 냄새 몇 해가 지나도 안 가시지,  
너는 바덴펠의 자긍심이요 기쁨이어라!  
  
클리프 보행자여, 높이높이 내달려라,  
불타는 크랙스 위에서, 하늘에 닿아라!  
클리프 보행자여, 높이높이 내달려라,  
우레처럼 스크리치를 내질러라, 결코 죽지 말지어다!
