# 니벤 모래톱을 건너서

ID: ext-e42ad76c3384ea56d530 / ESO 책 ID: 6686 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

(니벤 강의 노래)  
  
시로딜에서 토팔 만까지  
니벤의 등줄기는 드넓고  
레이야윈 부두에는 멋진 배들이  
아침 밀물을 기다린다네.  
  
알레스웰에서 광석을 싣고  
웨예에서 콜로비안 붉은 포도주를  
브라빌 항구에서 목재를 실어  
블랙우드 머리를 향해 항해했다네.  
  
코러스  
하나, 둘! 하나, 둘! 멀리, 정확히 던져라!  
어이, 측연수, 표식을 읽어라!  
짙은 머크 속에 얕은 여울이 도사리나니  
니벤 강을 가로질러!  
  
토르발에서 사탕수수를 사고  
사우스포인트에서 모피와 염료를  
대거폴에서 몽땅 팔아 치우고  
스트로스 므카이에서 술을 마셨다네!  
  
골드 코스트에서 실크와 와인을 가득 싣고  
우리는 다시 고향을 향해 돌아선다네  
레이야윈 마을에서 내 연인이 기다리나니  
그 사랑하는 선원을 기다리며!  
  
코러스  
하나, 둘! 하나, 둘! 멀리, 정확히 던져라!  
어이, 측연수, 표식을 읽어라!  
파도 아래엔 네레이드가 숨어드나니  
니벤 강을 가로질러!  
  
코러스  
하나, 둘! 하나, 둘! 멀리, 정확히 던져라!  
어이, 측연수, 표식을 읽어라!  
선원들이 물거품 위를 누비나니  
니벤 강을 가로질러!
