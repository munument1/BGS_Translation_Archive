# 모든 고유물 수집가를 찾습니다!

ID: ext-f2066d84adf0be8c0309 / ESO 책 ID: 6036 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

고유물에 열정을 품고 계십니까? 고대의 유물에 가슴이 두근거리십니까? 문화와 역사를 향한 매혹이 밤잠을 설치게 합니까? 손을 더럽히는 일을 즐기십니까?  
  
고유물 수집가 협회가 가슴 뛰는 새로운 기회를 위해 유능한 학자, 고대학자, 역사 박물학자, 그리고 탐험가를 구합니다.  
  
세상을 둘러보십시오! 잊힌 유물을 되찾으십시오! 고대의 수수께끼를 푸십시오! 흙 속에서 무언가를 파내십시오!  
  
관심 있는 분은 솔리튜드의 구윌림 북부 별관에 있는 베리타 누미다에게 문의하시기 바랍니다. 역사에 당신의 이름을 새기십시오. 고유물 수집가 협회에 가입하십시오!  
  
레지누스 부카  
  
(부기: 높은 지력과 신비술에 대한 타고난 재능을 지닌 자만 지원할 것. ―베.누.)
