# 동쪽에서 온 공포

ID: ext-1cefa7b7af5158f2038d / ESO 책 ID: 5715 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

악마들이 케나르티의 땅에 들이닥쳤을 때  
그녀는 이것이 운명임을 알았다  
그녀의 자식들은 마지막까지 맞섰고  
진홍색 관문을 열어젖혔다  
  
맨 먼저 당당하고 강력한 알코시가 왔다  
황금빛 갈기 위에 황금 왕관을 쓴 그는  
이것들이 이 땅에 있어선 안 됨을 보았고  
반드시 베어 없애야 함을 알았다  
  
뒤이어 강대한 로카즈가 내려왔다  
그의 검은 푸르게 빛나며 타올랐고  
그는 어둠을 다시 한번 몰아내며  
악마들을 꿰뚫어 버렸다  
  
마지막으로 니르니를 애도하는 허씬이 왔다  
그는 뼈로 그녀의 돌무덤을 쌓았으니  
우거진 푸른 숲에서 검게 물든 바다까지  
홀로 그녀를 굽어살피었다
