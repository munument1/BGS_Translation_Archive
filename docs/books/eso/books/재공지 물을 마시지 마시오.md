# 재공지: 물을 마시지 마시오

ID: ext-dd41deee9c7ce01805a8 / ESO 책 ID: 735 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

흐랄루 호수의 물은 절대 마시지 마라. 우리가 호수에 풀어 넣은 혼합물은 유달리 독하다. 물은 이곳 주민들 몫으로 남겨 두고, 우리 식구들은 강건하고 건강하게 지키도록 하자!  
  
그리고 명심해라. 나르시스 주변에서 이상한 낌새를 채거나 수상한 움직임을 발견하거든, 호숫가 야영지 한복판에 있는 지휘관 싼돈에게 보고하라.
