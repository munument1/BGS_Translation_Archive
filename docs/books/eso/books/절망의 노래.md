# 절망의 노래

ID: ext-60fadb48a271e0e845e1 / ESO 책 ID: 667 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

작자 미상  
  
운명에서 찢겨 나온 해답의 기억  
기다리지 못하는 모든 자의 파멸.  
  
황혼과 새벽에는 장미 여왕이 다스리나  
밤의 도둑들은 여전히 어둠을 차지한다.  
  
녹색 드래곤의 숨결이 구름과 웅덩이를 더럽히고  
고요한 거미는 표식을 새기는 거미줄을 짜낸다.  
  
깨어진 맹세와 배신자의 음모,  
사냥꾼의 뿔피리와 벼려진 창은  
  
소원을 헛되이 스러질 약조로 만드나니  
광기가 나타나려는 자들을 사로잡을 때.  
  
삶이 죽음을 거꾸로 뒤집어 세우고  
달콤한 욕정이 핏빛 웅덩이로 뛰어들 적에.  
  
흘릴 눈물 없이 저주에서 벗어나라  
악몽이 홍수처럼 밀려들 적에.  
  
질병과 역병은 삶의 끝이 아니니라  
투쟁의 수확자에게 길들여진다면.
