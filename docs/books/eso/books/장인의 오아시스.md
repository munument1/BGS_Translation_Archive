# 장인의 오아시스

ID: ext-ff30ca0486f218d2f15e / ESO 책 ID: 2515 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

오아시스를 찾아 사막을 떠도는 길이신가?  
  
레키의 날이 눈앞에 있으나, 이 유적에서 잠시 발걸음을 멈추고 소용돌이치는 모래의 고요로부터 배움을 얻으라.  
  
움직이고, 덮고, 드러내되 오직 필요할 때에만 하라. 바람을 따라 흐르라. 마음을 놓아라. 그리고 가는 곳마다 아름다움을 빚어내라.
