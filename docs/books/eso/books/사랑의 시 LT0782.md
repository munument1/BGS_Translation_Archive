# 사랑의 시 LT0782

ID: ext-84b27e907e380aa97de3 / ESO 책 ID: 4600 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

[시 시작]  
  
그대의 우월함은 계산을 거스르고,  
나의 심장(은유적 표현)은 피스톤처럼 고동치며,  
그대와 신체적 접촉이 이루어질 때면 언제나,  
나의 골반 및/또는 무릎 경첩이 진동하노라,  
또한, 그대 얼굴의 대칭은 나를 흡족하게 하노라.  
  
[작문 종료]
