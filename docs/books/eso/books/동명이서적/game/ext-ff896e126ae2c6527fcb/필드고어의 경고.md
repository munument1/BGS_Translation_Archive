# 필드고어의 경고

ID: ext-ff896e126ae2c6527fcb / ESO 책 ID: 1254 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

카조크,  
  
코눈라이카르 기간에는 네 병사들이 윈드헬름으로 몰래 숨어들고 싶어 안달이 날지도 모른다. 허나 자네가 그들을 단단히 단속해야 한다.  
  
방법은 자네에게 맡기겠다. 다만 도시 안에서는 다른 계획이 진행되고 있다. 자네나 자네 병사들이 무엇 하나라도 그르쳤다는 걸 내가 알게 되면, 그땐 자네 목이 달아날 줄 알라!  
  
— 필드고어 오크종사
