# 성 펠린 기사단 단서

ID: ext-44cc7751539ac05e2f81 / ESO 책 ID: 7260 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

바다 건너 옛 뱅코라이로 가라  
주둔지의 길을 따라 내려가라.  
  
리치포크의 분노에 맞서  
방비를 굳히는 병사들이 보이는 곳.  
  
명멸하는 푸른 불꽃이  
밤마다 부르는 곳.  
  
그곳에 그대의 카드가 잠드니  
성 펠린의 기쁨이라.
