# 현상수배: 족장

ID: ext-201e3737fd479f22ecd2 / ESO 책 ID: 856 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

현상수배—생사불문, 시체라도!  
  
스스로를 "족장"이라 칭하는 산적.  
  
에본하트 조약 백성들을 상대로 저지른 다음의 죄목으로 수배함:  
—살인  
—강도  
—가축 침해  
—귀부인에 대한 무례  
  
"족장"의 목(몸통은 선택)에 현상금을 내건다.  
  
가장 가까운 조약 관리에게 가져올 것.
