# 현상수배: 테르부르 사드리

ID: ext-e79ee7e08b656398cf47 / ESO 책 ID: 504 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

테르부르 사드리는 셀로스 가문의 셀로스 당주를 살해한 혐의로 수배되었다.  
  
무장한 위험인물로 간주된다.  
  
테르부르 사드리가 마지막으로 목격된 곳은 동부 데샨이었다.  
  
테르부르 사드리의 행방에 관해 아는 바가 있는 자는 네르비나 셀로스에게 알려야 한다.
