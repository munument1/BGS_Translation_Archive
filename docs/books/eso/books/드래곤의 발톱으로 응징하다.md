# 드래곤의 발톱으로 응징하다

(불굴의 200인이 부른 전투의 노래)  
  
우리는 드래곤나이트다. 우리는 드래곤이다.  
  
우리를 공격한다면, 발톱이 맞이하리라.  
  
우리를 내려친다면, 스파이크를 삼키게 되리라.  
  
우리를 다치게 한다면, 우리의 상처는 도로 아물리라.  
  
우리를 분노케 한다면, 불타 버리리라.  
  
우리에게서 달아난다면, 우리가 덮쳐 파운스하리라.  
  
그대는 이길 수 없고, 우리는 질 수 없도다.  
  
우리는 드래곤나이트다. 우리는 드래곤이다.
