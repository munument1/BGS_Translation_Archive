# 장막의 알레리스

ID: ext-56e0b835ef5dc4d7f5f4 / ESO 책 ID: 1107 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

축복받은 시련의 초대 챔피언 알레리스는 그 칭호를 40년 동안 지켜냈다. 환영 마법을 다루는 솜씨와 능란한 검술로 명성이 자자하였으니, 투기장에서 그 실력에 견줄 만한 자도, 군중의 환호를 그만큼 사로잡은 자도 드물었다.  
  
칭호를 빼앗은 자: 없음  
  
패배를 안긴 자: 까마귀를 부르는 자
