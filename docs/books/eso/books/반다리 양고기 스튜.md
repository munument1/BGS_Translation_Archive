# 반다리 양고기 스튜

ID: ext-7a7e8218c03156e9881f / ESO 책 ID: 786 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

8인분  
  
깍둑썬 양고기 2파운드  
육수 1잔  
큰 양파 1개, 다진 것  
작은 토마토 4개, 으깬 것  
감자 2파운드, 껍질 벗겨 4등분한 것  
  
재료를 큰 무쇠 냄비에 담아 불 위에 걸어 둔다. 버터 한 덩이를 넣고 휘젓는다. 고기가 노릇해지면 따뜻한 육수를 한 주전자 붓는다. 냄비를 불 가장자리로 밀어 두고 익힌다. 필요하면 소금이나 후추를 더한다.  
  
상하면 내다 버린다.  
  
대신 케이크나 먹어라.
