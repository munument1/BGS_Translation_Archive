# 재판관의 알림

ID: ext-11c778b2238b2bb607fb / ESO 책 ID: 1606 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

명심하라.  
  
나는 내 법정이 흥미진진하고 짜릿하기를 바란다. 또한 우리의 사건들이 신속히 결말에 이르기를 바란다. 그러한 까닭에, 모든 데이드라 집행관들에게 다시 일러두노라. 필멸자는 데이드라보다 약하고 무르다는 것을. 우리의 새 포로들은 웬만한 상처에서 쉬이 회복하지 못하니, 나는 그들이 선고를 받을 만큼은 성한 상태이기를 바란다.  
  
그들을 상하게 하지 말라. 여기에는 사지 절단, 살갗 벗기기, 내장 적출, 참수, 즉결 처형이 포함되나 이에 국한되지는 아니한다. 적어도 판결이 내려지기 전까지는 말이다.  
  
부디, 이 필멸의 마법사들 앞에서 자제하고, 그들을 망가뜨리지 말라. 나는 이 장난감들과 되도록 오래 놀고 싶구나.  
  
자, 이제 정의라는 것을 베풀러 가 보자! 몰라그 발의 영광을 위하여!  
  
— 재판관 지벤
