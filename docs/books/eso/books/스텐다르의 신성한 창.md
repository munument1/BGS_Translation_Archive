# 스텐다르의 신성한 창

ID: ext-53601d249c1b7669ff56 / ESO 책 ID: 2368 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

스텐다르의 신도, 빛나는 프톨루스 지음   
  
불경스러운 모든 것을 무찌르고,   
  
그 끝과 광휘로 꿰뚫으며,   
  
그 기운으로 우리를 드높이고,   
  
악독한 적을 무력케 하나니.   
  
데이드라, 언데드, 야수와 야수인간,   
  
흉물들을 쳐 쓰러뜨리도다.   
  
우리를 다시 거룩케 하소서, 견고하신 스텐다르여,   
  
창과 왕관과 더불어 굳건하소서!
