# 군단의 도착 단서

마차 위에 올라, 그곳으로 향하라  
성 펠린이 끝없는 안식에 든 곳으로  
  
죽은 자들은 은밀히 무릎 꿇어 기도하거나  
신음하며 변명을 늘어놓아 방비하니  
  
성인들의 살피는 시선 아래  
한 쌍이 마주 서 있는 곳에  
  
플레이어여, 그대의 카드가 여기 잠들었노라  
군단의 나팔 소리 울려 퍼지는 가운데
