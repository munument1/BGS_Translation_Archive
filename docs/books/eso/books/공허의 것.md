# 공허의 것

ID: ext-992cc605270bd12ca9d2 / ESO 책 ID: 5362 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

니스우 제울름 지음  
  
영원한 공허인 것  
최초의 창조자, 최후의 파괴자  
무에서 태어난 모든 것은  
다시 무로 돌아가리라  
  
황혼 속으로 녹아드는 낮  
날카로운 일격에 빼앗기는 생명  
부스러져 먼지가 되는 돌  
다시 피어나 생명이 되는 죽음  
  
원치 않는 변화, 필요한 변화  
자라고, 스러지고, 다시 태어나니  
어둠과 같이, 그대의 죽음과 같이  
사그라드는 숨결 위에 흩뿌리는 공허의 말  
  
계절은 변하노라, 우리의 뜻에도 불구하고  
만물은 변하노라, 우리의 두려움에도 불구하고  
공허인 것을 바라보라  
눈을 활짝 뜨고 바라보라
