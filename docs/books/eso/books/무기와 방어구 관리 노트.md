# 무기와 방어구 관리 노트

ID: ext-86500dca844799a72901 / ESO 책 ID: 1362 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

가죽은 끊임없이 축축한 상태에 놓이면 그리 오래가지 못한다. 밤마다 닦아 광을 내어도 표면에 곰팡이가 피어나, 광택을 흐리고 그 견고함을 좀먹는다.  
  
금속은 다르되 그리 다르지 않은 운명을 맞는다. 녹이 안에서 밖으로 갉아먹으며, 보호받지 못한 부위를 부풀려 터뜨리고 부스러뜨린다. 이음매는 끊임없이 기름칠하지 않으면 뻣뻣하게 굳는다.  
  
병사들이여, 그대들의 무기와 방어구를 보전하라! 가능하다면 장비를 축축한 바닥 위에 매달아 두라. 그대들이 숨을 쉬어야 하듯, 그것들 또한 숨을 쉬어야 하나니, 알려진 적과 알려지지 않은 적, 우리가 맞서도록 정해진 그 모든 적으로부터 그대들을 지켜줄 유일한 방패가 바로 그것들이기 때문이다.  
  
서명: 보급관 집무실
