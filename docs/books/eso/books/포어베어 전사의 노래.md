# 포어베어 전사의 노래

ID: ext-de340f5c7c59ba8728d3 / ESO 책 ID: 1632 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

아카토시여, 저의 힘은 당신의 손에서 비롯되니,  
적들은 저의 검 앞에 쓰러집니다.  
그들의 비명이 들리시나이까?  
죽음을, 그들은 외칩니다.  
죽음을, 저는 노래합니다.  
허나 죽음은 그들의 것이요, 저의 것이 아닙니다.  
  
적의 빛깔을 칼날에서 닦아 내라.  
적의 빛깔을 방패에서 닦아 내라.  
승리는 우리의 것이니!  
  
스텐다르여, 저의 무기가 오직 이러할 때에만 떨어지게 하소서.  
정의를 위하여, 올바른 길을 위하여.  
저의 간청이 들리시나이까?  
정의를, 그들은 기도합니다.  
정의를, 저는 노래합니다.  
정의는 저의 것이요, 또한 그들의 것입니다.  
  
적의 빛깔을 칼날에서 닦아 내라.  
적의 빛깔을 방패에서 닦아 내라.  
승리는 우리의 것이니!  
  
의로운 자의 길은 자비이며,  
약한 자를 향한 연민이기에.  
제가 당신의 검과 방패를 들어도 되겠나이까?  
자비를, 그들은 애원합니다.  
자비를, 저는 베풉니다.  
불의한 자에게는 신속한 죽음을!  
무자비한 자에게는 더딘 죽음을!  
  
적의 빛깔을 칼날에서 닦아 내라.  
적의 빛깔을 방패에서 닦아 내라.  
승리는 우리의 것이니!
