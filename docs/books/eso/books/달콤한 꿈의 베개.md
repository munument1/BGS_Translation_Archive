# 달콤한 꿈의 베개

ID: ext-d7bc5e14c1566b17a635 / ESO 책 ID: 4827 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

호노리아 아우러스의 시   
렐릭마스터 글레나디르가 옮겨 적다  
  
베개에 머리를 누이니  
감은 눈 뒤로 달콤한 꿈이 어린다  
다시금 잠이 찾아오기를 갈망하노라  
낮은 그 거짓으로 나를 잠기게 하리니  
  
그때 내 연인이 곁에 눕고  
미소는 환하며 살결은 빛나니  
그 순간 죽음도 그녀를 붙들지 못하나  
아침이 오면 그녀는 떠나야 하리  
  
나는 다시 잠들어  
영영 깨지 않으리  
오늘 밤 내 영혼을  
거두어 가리라
