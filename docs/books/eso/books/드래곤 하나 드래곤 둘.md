# 드래곤 하나 드래곤 둘

ID: ext-4eeba58456c0d7cc43f1 / ESO 책 ID: 5612 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

드래곤 하나, 드래곤 둘  
붉은 드래곤, 푸른 드래곤.  
  
하나는 우리에서 풀려나고  
하늘 가득 모인 무리는 살기 어린 분노로다.  
  
어떤 놈은 잔혹하고, 어떤 놈은 날래며  
어떤 놈은 스치는 길에 불을 뿜는다네.  
  
드래곤은 그대를 얼려 버리거나   
산산조각 나도록 태우거나  
포효로 날려 버리거나  
구덩이에 처박는다네!  
  
하늘을 올려다보라  
동틀 녘이나 한밤중에  
그대 어쩌면 드래곤을 보리라  
살기 어린 비행 속에서!  
  
무엇이 드래곤을 성나게 하나?  
어이하여 머무는가?  
나는 알지 못하니  
그저 줄행랑칠 뿐!
