# 알 탄생의 표식

ID: ext-326cff3d899469415cf3 / ESO 책 ID: 726 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

와켐과 다이-셴에게  
첫 산란에서 셋, 활력을 품고 태어나다.  
  
바르-진과 슬픔을-흘려보내는 자에게  
첫 산란에서 하나, 알 이빨이 껍데기를 깨뜨렸다. 좋은 징조다.  
  
네포쉬와 라나에게  
둘째 산란에서 둘. 첫째는 껍데기와 씨름했으나, 둘째는 그렇지 않았다.  
  
섀도우스케일에게  
셋째 산란에서 다섯. 시디스께서 그 필요를 말씀하셨으니, 우리는 응답해야 한다.
