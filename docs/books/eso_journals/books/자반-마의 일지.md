# 자반-마의 일지

ID: ext-c09ecf30b6172ddf6f82 / ESO 책 ID: 1515 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

대농장의 사정이 달라졌다. 빚쟁이들이 더는 모습을 드러내지 않고, 누님은 늘 비싼 고기를 사들인다.  
  
이 돈이 다 어디서 났단 말인가? 올해 작물은 형편없었다. 지난달에 겨우 열 자루를 거둬들였을 뿐이다.  
  
누님은 어째서 자꾸 어디론가 사라지는 걸까? 때로는 몇 시간씩 나가 있다가도 아무 일 없었다는 듯이 행동한다. 아버지는 한마디도 하지 않으신다.  
  
이건 옳지 않다.
