# 자카에 관하여

ID: ext-46ec4b9d90de9f33b789 / ESO 책 ID: 7157 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

보스는 그 덩치 큰 고양이 자카가 쓸모 있을 거라고 장담했다. 한데 이놈은 기침에 쌕쌕거리기만 할 뿐, 힘이라곤 별로 없어 보인다. 브라슬라는 영락없이 사기 물건을 떠안은 셈이다. 오스티토스 모렐로를 한 번 더 찾아가야겠다고 한다.  
  
그동안 우리는 고양이를 우리에 가두고 빵과 물이나 던져 준 뒤, 다들 가까이 가지 말라고 일러두었다. 병이 옮는 놈일 수도, 꾀병을 부리는 걸 수도, 죽어 가는 걸 수도 있다. 알 바도 아니고, 신경 쓸 바도 아니다.
