# 나리나가 타보에게 보내는 편지

ID: ext-6816484186efce795668 / ESO 책 ID: 128 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

사랑하는 타보에게,  
   
부디 한시라도 빨리 센티넬로 돌아와 줘요. 빚쟁이가 들이닥쳤는데 돈이 모자라면, 그자가 무슨 짓을 할지 생각만 해도 무서워요. 유물 한 다스만 있어도 우리 빚을 갚고도 남을 거예요.  
   
영원히 당신의 사람,  
  
나리나
