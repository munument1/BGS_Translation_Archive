# 자비에 대하여

ID: ext-28c554edd2e099584b24 / ESO 책 ID: 612 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

모두에게 고한다,  
  
자비는 나약함이다. 명심하라. 우리가 이곳에 온 것은 해골을 거두기 위함이다. 약한 자를 노예나 애완동물로 끌고 다니는 것은 말라카스에 아무런 명예도 되지 못한다.  
  
말라카스의 길이 아니라면, 서약군의 길도 아니다.  
  
— 그루즈낙
