# 카마리노가 보낸 편지

ID: ext-8870ef363f057749b7e1 / ESO 책 ID: 659 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

가장 사랑하는 누이에게,  
  
우리 생각이 맞았어. 찬장에서 빵을 훔쳐 가던 건 다름 아닌 아버지였어. 어머니는 고래고래 소리치셨고, 우리는 배꼽이 빠지도록 웃었지. 네가 곁에 있었다면 더 신나게 웃었을 텐데.  
  
어서 나아라, 우리 막내야. 아우리엘께서 너를 굽어살피시기를.  
  
— 카마리노
