# 아칼리아 대장의 메모

ID: ext-b2db8d56c83525a0c84f / ESO 책 ID: 1533 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

엔가나스에게,  
  
네 약탈품 몫을 여기 보낸다. 그 더러운 사제 놈들을 다른 누구보다 많이 베었으니, 그 상으로 마라의 단검을 내리겠다. 돌불꽃 숭배자가 성배 값을 치르고 나면, 너는 추가로 한몫의 금화를 더 받게 될 것이다.  
  
— 아칼리아 선장
