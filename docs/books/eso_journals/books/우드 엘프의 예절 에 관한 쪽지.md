# "우드 엘프의 예절"에 관한 쪽지

ID: ext-aa7afef9a34aec03e2ed / ESO 책 ID: 2127 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

글라델에게,  
  
안식처의 정보원이 확인해 줬어. 오래전부터 비웃음거리였던 「우드 엘프의 예절: 임페리얼의 시점」 쉰 부가 오늘 도착했지. 그 행선지가 어디게? 알트머 대사관이야. 그자들이 우리를 어떻게 보는지가 이걸로 다 드러나는 거지—꽃 한 송이 밟히는 꼴만 봐도 길길이 날뛰는, 허세나 부리는 멍청한 촌뜨기로 보는 거야.  
  
—이론드가
