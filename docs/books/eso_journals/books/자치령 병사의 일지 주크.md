# 자치령 병사의 일지: 주크

ID: ext-46191dc14182cec5f087 / ESO 책 ID: 1352 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

도착했을 때 우리는 아무런 저항도 받지 않았다. 마을은 코스린기 한 명을 제외하면 텅 비어 있었다.  
  
세도르미스 키스톤에 관해 알아내려고 온갖 방법을 동원했지만, 그자는 이상하리만치 웬만한 고문에는 끄떡도 하지 않는다. 마치 고통을 느끼지 못하는 듯하다. 상처도 놀라운 속도로 아물어 버린다.  
  
마법사들은 습지를 파헤치느라 바빠 내게 의견 하나 내주지 않는다. 좀 서둘러 줬으면. 조만간 뭐라도 내놓지 못하면, 탈모어가 내 목을 가만두지 않을 것이다!
