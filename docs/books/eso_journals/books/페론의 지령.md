# 페론의 지령

ID: ext-fb0664be2acf54422135 / ESO 책 ID: 7102 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

관심 가져줘서 다행이군, 페론. 스톤로어 숲에서 지도 조각을 되찾아 오면, 그 수고에 정직하게 금화로 값을 치르지. 드루이드들이 자네를 귀찮게 하진 않겠지만, 그 바깥은 거친 야생이니 발밑을 잘 살피게. 조각은 뒤포르 부두에 있는 내게 가져오게.
