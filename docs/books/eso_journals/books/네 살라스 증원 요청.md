# 네 살라스: 증원 요청

ID: ext-8515c52dea264bd32e5f / ESO 책 ID: 2048 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

긴급—신속한 회신 요망.  
  
대거폴 동맹이 회색 습지 북쪽의 네 살라스 유적에 침투하였음. 놈들의 수가 불어나는 양상으로 보아, 그랏우드로 통하는 은폐된 통로를 확보한 것으로 판단됨. 본관에게는 그 진격을 저지할 병력이 없음.  
  
즉시 증원을 파견해 주기 바람.  
  
— 세인딜
