# 아카쉬가 보낸 쪽지

ID: ext-5280a55ea87066b3b4b0 / ESO 책 ID: 1784 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

고용주께서는 제단마다 아홉 종류의 서로 다른 야수에게서 뼈 아홉 개를 원하신다.  
  
섞지 마라. 대충 하지 마라.  
  
그러면 그분께서 아시게 될 테고, 기뻐하지 않으실 거다. 오라네스가 기뻐하지 않으면, 나도 기쁘지 않다.  
  
— 아카쉬 그라-말
