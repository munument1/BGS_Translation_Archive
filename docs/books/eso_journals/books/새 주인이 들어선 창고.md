# 새 주인이 들어선 창고

ID: ext-0a5fc4344fddb8baae98 / ESO 책 ID: 3446 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

<<1>>의 부재로 창고 직원들 사이에 동요가 일고 있다는 것을 우리도 알고 있다.  
   
놀랄 것 없다. 창고는 새로운 주인—안정된 주인의 손으로 넘어갔다. 늘 그래 왔듯 일에 힘을 쏟으라. 그대들이 버는 돈은 예전과 다름없이 쓰일 것이다.  
   
—감독관 이즈리나  
—감독관 토르크밍
