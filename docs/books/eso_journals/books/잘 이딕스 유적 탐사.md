# 잘 이딕스 유적 탐사

ID: ext-e6ea4ea6c9a6408be6cb / ESO 책 ID: 670 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

이곳은 참으로 메마른 수확지로구나. 잘 이딕스는 스캐빈저들의 땅이다. 생각해 보면, 내 동족은 쇠똥구리나 진드기새처럼 살아간다. 살아남기 위해 다른 문화의 잔해를 뒤지면서 말이다.  
  
그것도 이 유구한 폐허의 영광 한가운데서! 내 짐작에 잘 이딕스의 잔미어는 섀도우펜에서도 가장 오래된 축에 들 것이다. 이곳에서 우리 선조들의 유물의 흔적이라도 찾을 수 있다면 좋으련만, 설령 무언가 있었다 한들 진작에 약탈당했을까 두렵다.  
  
발빈과 나는 내일 북쪽으로 떠난다. 어쩌면 다른 곳에는 손때 묻지 않은 보물이 기다리고 있을지도 모른다.
