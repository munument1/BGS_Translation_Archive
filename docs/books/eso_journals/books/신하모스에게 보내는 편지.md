# 신하모스에게 보내는 편지

ID: ext-2ff59d3cf345fb30e2b1 / ESO 책 ID: 2522 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

아아, 어여쁜 신하모스여, 어찌 그리 군침 도는 선물로 이 몸을 흐뭇하게 하시는가!  
  
내 허리둘레를 살피고 있음을 잘 알면서도, 그대는 여전히 버터 바른 스캠프 너클을 보내는구려.  
  
(그나저나, 정말 맛있었다오!)  
  
— 캐드웰 경
