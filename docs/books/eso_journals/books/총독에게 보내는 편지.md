# 총독에게 보내는 편지

ID: ext-ae5f79f7312190980d48 / ESO 책 ID: 5818 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

펜타르크 자로스에게,  
  
준비는 끝났다, 나의 브레튼 형제여. 우리는 의식을 시작할 채비를 마쳤다.  
  
최근 화물은 킬크리스 사원으로 보내라. 자매 암브리트가 모든 것을 요긴하게 쓸 것이다.  
  
참으로 잘해 주었다.  
  
나의 다음 명령을 기다려라.  
  
R
