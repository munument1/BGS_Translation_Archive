# 재미난 일이야, 실

ID: ext-abcb0284c52c6588acfa / ESO 책 ID: 1604 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

실에게,  
  
네 은닉처에서 문슈거를 좀 빌렸다고 해서 — 다시 채워 놨다니까, 알아둬 — 날 반쯤 죽도록 겁줄 권리가 생기는 건 아니지.   
  
문틈으로 편지나 밀어 넣고, 날 죽이라고 암살자를 보냈다는 둥 넌지시 흘리다니. "우리는 알고 있다," 라니, 참 나! 아주 우습군.  
  
헨로르
