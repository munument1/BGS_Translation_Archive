# 틸라니의 편지

ID: ext-1bf8d0647ec32eb3e330 / ESO 책 ID: 341 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

라나에게  
  
변명은 이제 지긋지긋해. 어제 훈련은 수치스러운 꼴이었어. 내가 지휘하던 시절엔 이런 문제는 단 한 번도 없었다고.  
  
저 젖이나 홀짝이는 놈들 몇몇보단 차라리 롤룬다가 더 나은 병사가 되겠어!  
  
그것들을 한데 모아. 조약이 우리에게 달려 있다.  
  
— 틸라니 스노우-본
