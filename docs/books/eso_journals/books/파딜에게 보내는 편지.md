# 파딜에게 보내는 편지

ID: ext-ab0f8e883385521d9b7c / ESO 책 ID: 1395 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

파딜에게,  
  
후잘이 굶주린다! 내가 길들인 뱀은 많으나, 그를 길들일 수 있는 자는 아무도 없도다! 그의 용뱀 같은 욕망에 사막이 쿵쾅거리며 울린다. 그는 신선한 살점을 갈망한다. 방심한 자들을 샌드블로운 광산으로 보내라. 후잘은 반드시 포식해야 하느니라.  
  
미루다
