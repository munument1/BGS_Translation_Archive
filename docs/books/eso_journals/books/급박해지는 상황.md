# 급박해지는 상황

드라실라가 더없이 집요하게 구애를 멈추지 않습니다. 단호하게 대하려 애써 보았으나, 도리어 저를 손에 넣겠다는 결심만 굳게 만든 듯합니다. 여간 난처한 일이 아닙니다.  
  
게다가 친애하는 로렌트 여사께서는 지금쯤 거의 굶주리고 계실 것입니다. 제가 일러드리지 않으면 끼니조차 챙기시는 걸 잊으시니 말입니다.
