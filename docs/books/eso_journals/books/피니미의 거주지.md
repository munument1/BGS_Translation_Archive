# 피니미의 거주지

ID: ext-7f3da5c535c5bcb85c80 / ESO 책 ID: 7038 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

오직 자매들만이 이 거처에 들어올 수 있다  
  
섬의 중심에 가장 가까운 기단 위에 신성한 탄나 잎을 놓아라  
  
기사의 검이 결코 녹슬지 않는 기단 위에 나의 선한 자매의 숄을 놓아라  
  
동물들이 죽어가는 기단 위에 배신자의 갈탄을 놓아라  
  
배신자의 이름에 저주가 있으라
