# 걱정할 것 없다

H에게,  
  
지난번 실수는 사과하오. 우리 공급책이 의심을 품기 시작했소. 너무 마음 쓰지는 마시오. 마땅히 먹여야 할 입들은 챙길 테니.  
  
길 잃은 그대의 새는 되찾아 왔소. 배가 폭풍에 휘말렸으나, 살릴 수는 있을 듯하오. 다음 보름달이 뜰 때까지 그대 손에 들어오지 않거든, 우리는 발각된 것이니 서신은 끊어야 하오.  
  
— R
