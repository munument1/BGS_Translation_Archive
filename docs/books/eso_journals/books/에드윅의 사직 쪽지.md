# 에드윅의 사직 쪽지

ID: ext-072e770a25178778fc7a / ESO 책 ID: 1982 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

고작 손가락뼈 하나로 언데드 무리를 어찌하겠다는 거야? 우리에겐 승산이 없어. 헛된 희망에 매달리는 건 바보들뿐이지.  
  
나는 가장 가까운 항구로 가서 제일 먼저 떠나는 배에 오를 거야. 따라올 생각 마. 나는 아르케이를 위해 죽지 않을 테니까.  
  
—에드윅
