# 시로 대장에게 보내는 메모

ID: ext-22d77e367a8f4c27f63d / ESO 책 ID: 941 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

할 수 있는 건 전부 했다. 그들을 설득해 네 목숨을 살리고 지휘권까지 지키게 해 줬으니 고맙게 여겨라.   
  
이걸로 우리 빚은 청산됐다. 다시는 네 소식을 듣고 싶지 않다.  
  
그리고 몸조심해라, 영감.  
  
마구스 장군 셉티마 탄, 제7군단
