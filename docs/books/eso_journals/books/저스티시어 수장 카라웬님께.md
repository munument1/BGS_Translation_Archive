# 저스티시어 수장 카라웬님께

ID: ext-5700e4b4fc389722614a / ESO 책 ID: 5083 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

저스티시어 수장 카라웬님께,  
  
저희 임무는 실패했습니다. 저스티시어 아바나이레가 저희를 배신하고 제 병사 여럿을 죽였습니다. 그녀는 토르-헤임-카드로 달아났습니다. 저는 남은 병력으로 그녀를 추격하고 있습니다. 별들이 굽어살피신다면, 진주를 되찾을 수 있을 것입니다.  
  
이 전갈이 닿기를 바라며 병사 하나를 보냅니다. 증원군을 보내 주십시오. 이 유적에는 아바나이레 말고도 도사리고 있는 영혼들이 더 있습니다.  
  
텔로무어 대장
