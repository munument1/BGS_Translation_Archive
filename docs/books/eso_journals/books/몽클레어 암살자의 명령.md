# 몽클레어 암살자의 명령

ID: ext-604ee862d04c4f38bc2e / ESO 책 ID: 1989 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

몽클레어 가문은 이번 일에서 그대가 보여 준 헌신과 인내에 감사를 표한다. 표적이 확인되면 그대가 훌륭히 임무를 완수하리라 믿는다.  
  
표적 명단을 마저 작성하는 동안, 도시에서 멀리 떠나지 말라. 추가 지시는 곧 전하겠다.
