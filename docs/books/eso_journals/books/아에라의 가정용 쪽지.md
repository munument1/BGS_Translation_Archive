# 아에라의 가정용 쪽지

ID: ext-72e12a5732603fdca3e9 / ESO 책 ID: 348 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

- 덴스카 양말 꿰매기  
- 트린힐드에게 바느질 가르치기 (하!)  
- 다지에게 활 훈련 다시 부탁하기 (그 어깨란!)  
- 마소르 셔츠 꿰매기 (틸라니에게 갚는 셈)  
- 리트렉에게 아이먼 잡일 돕게 시키기  
- 그 대신 아이먼에게 연어 구이 만들어 달라 하기  
- 라나와 세인 저녁식사에 초대하기 (그 둘 얘기 트린힐드에게 다시 묻기)  
- 엘크 고기 손질하기  
- 돼지 등심 훈제하기  
- 롤룬다에게 종이 돌려주기  
- 라나 일로 틸라니와 다시 얘기하기
