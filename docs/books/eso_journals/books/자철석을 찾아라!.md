# 자철석을 찾아라!

ID: ext-c6d6920cbd4388b6a4f3 / ESO 책 ID: 6861 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

아직 물에 떠 있는 배라면 무엇이든 부숴버려라. 짓다 만 것이든, 무너져 가는 것이든, 한 번도 물에 띄워본 적 없는 것이든. 상관없다. 노예들을 시켜 자철석이 나올 때까지 널빤지를 한 장도 남김없이 뜯어내라.   
  
노예가 죽거든, 항구를 준설하는 나머지 퉁퉁 불은 시체들 틈에 끼워 일을 시켜라. 찾아낼 수 있는 자철석은 하나도 빠짐없이 거둬들이라는 명령이다. 그러니 넉넉히 챙겨라. 안 그러면 드레드세일 여왕께서 우리 모두를 용골에 매달아 끌어버리실 테니.
