# 공고문: 서약 임무

ID: ext-34df5bc725224094248b / ESO 책 ID: 4012 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

주목하라, 이 술주정뱅이들아.  
  
너희가 즐겨 찾는 전장들의 서약을 누가 맡고 있는지 기억하는 일이, 그곳에서 칼부림하고 약탈하는 것보다 더 어렵다는 게 드러났다. 술기운이나 머리 상처로 정신이 혼미한 경우를 대비하여, 서약 제공자와 그 담당 지역을 여기에 정리해 둔다.
