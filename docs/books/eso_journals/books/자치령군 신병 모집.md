# 자치령군 신병 모집

ID: ext-e823c0ac26329213e9b9 / ESO 책 ID: 2296 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

마레닐 장군에게,  
  
자치령을 대표하여, 전쟁에 병력을 보충해 준 그대의 노고를 치하하노라. 그대는 내 신뢰가 옳았음을 입증해 주었다. 그대의 공적은 아이렌 여왕과 탈모어에게도 전해 두었다.  
  
허나 그대에게 더 많은 것을 요청해야겠다. 협약과 대거폴 동맹을 상대로 한 전쟁이 우리 자원을 한계까지 쥐어짜고 있다. 더 많은 전사가 필요하다.  
  
서부 엘스웨어 관문을 지나오는 모든 자에게, 무장을 갖추고 시로딜의 전장으로 서둘러 향하라 독려하라.  
  
보고는 계속 자하라이를 통해 보내도록.  
  
— 소르칼린 대장군
