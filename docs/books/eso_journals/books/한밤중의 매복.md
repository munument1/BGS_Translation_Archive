# 한밤중의 매복

ID: ext-19b4199531a7997f27ed / ESO 책 ID: 1574 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

악명 높은 카짓 전사 문-사이스가 소수의 측근을 이끌고 밤의 장막에 몸을 숨긴 채 버드나무숲으로 향했다. 그러나 야간 기동을 더없이 화려하게 펼쳐 보이던 차에, 보스머 수비대의 매복에 걸려 몰살당하고 말았다.  
  
수색 대상 유물:  
— 문-사이스의 유해  
— 문-사이스의 은빛 발톱
