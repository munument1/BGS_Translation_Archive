# 펠루스에게 보내는 쪽지

ID: ext-f07563e7dc598f42e177 / ESO 책 ID: 1530 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

펠루스에게,  
  
관문 잠그는 걸 잊지 마라. 지난번에 안 잠가 뒀을 때 물건이 여럿 사라졌다. 마라 사원에서 가져온 내 약탈품 몫이 여기 있다. 이 전리품을 손에 넣으려고 많은 자를 죽였으니, 만약 사라지기라도 한다면 그 책임은 전적으로 네게 묻겠다.  
  
— 아칼리아 대장
