# 레온스 가벤디엔에게 보내는 편지

ID: ext-c4ad1a061809fe358030 / ESO 책 ID: 2469 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

레온스에게,  
  
펠의 여정을 털겠다는 자네의 계략은 실로 탁월하군! 게다가 버려진 옛 요새를 이용하다니, 이 일대에 자네의 악명을 떨치게 한 그 치밀함이 그대로 드러나는걸세.  
  
보석은 내 기꺼이 사들이지. 물건이 손에 들어오거든 노스포인트로 나를 찾아오게.  
  
—라그라 선장
