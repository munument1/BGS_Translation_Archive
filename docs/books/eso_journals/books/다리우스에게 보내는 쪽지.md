# 다리우스에게 보내는 쪽지

ID: ext-873f635f161ddce708ad / ESO 책 ID: 1532 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

다리우스,  
  
자네 몫의 전리품일세. 마라 사원을 습격할 적에 자네는 용맹하고도 영민하게 싸워 주었네. 나는 내 소위들이 하나같이 넉넉한 보상을 받기를 바라네.  
  
성구함은 자네 뜻대로 하게. 간직하든 팔아치우든 말일세.  
  
— 아칼리아 대장
