# 로즈루스에게 보내는 편지

ID: ext-1649ff0371ee4d459aa5 / ESO 책 ID: 3217 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

로즈루스,  
  
자네 전언은 받았네. 출발 허가도 떨어졌어. 당분간은 나 혼자일세. 곧 도착하겠네.  
  
자네가 일에 전념할 수 있도록, 다들 자네를 성가시게 못 하게 내가 최선을 다해 막고 있네. 쉬운 일은 아니지만.  
  
그럼 이만,  
고루즈
