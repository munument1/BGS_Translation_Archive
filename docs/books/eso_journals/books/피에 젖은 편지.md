# 피에 젖은 편지

사랑하는 맙키르에게,  
  
밝은 달이 함께하기를, 내 사랑! 어젯밤 즈주룩이 단원들을 모아 우리 사정을 호소했어. 누줄라자와 하닐라르는 자카짓처럼 울부짖었지만, 결국 우리 친구들은 당신의 자유가 새 마차보다 더 중요하다고 결정했지. 돈을 모으려면 시간이 좀 걸리겠지만, 이 몸은 곧 당신을 만나리란 걸 알아. 로프피시 카르타그를 찾아. 당신을 내게로, 집으로 데려다줄 배의 선장이니까.  
  
사랑해,  
당신의 엘라사르하가
