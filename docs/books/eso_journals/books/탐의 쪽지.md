# 탐의 쪽지

마에르에게,  
  
내 편지를 무시하고 얼씬도 하지 않았기를 바라네. 만약 왔다면, 자네가 알아둬야 할 게 있어.  
  
우리가 늘 마시던 최고의 술은, 데시우스 영감이 곤드레만드레 취해 집까지 못 걷던 날마다 뉘어두던 그곳에 숨겨뒀네.   
  
옛 친구들이 마을 술을 죄다 비워버리기 전에, 어서 조용히 가면 몇 병쯤 슬쩍 빼낼 수 있을 거야.  
  
나는 곧 파 쇼어로 떠날 듯하네. 톨 파파께 자네 안부를 전해두지.  
  
탐
