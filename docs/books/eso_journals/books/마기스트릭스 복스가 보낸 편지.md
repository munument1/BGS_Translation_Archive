# 마기스트릭스 복스가 보낸 편지

ID: ext-c8b170cc54010c41af64 / ESO 책 ID: 2496 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

친애하는 마니볼에게,  
  
드레스 가문이 나의 마울본 대업을 지지해 주니 마음이 든든하오. 그대가 베푼 관대한 금화와 자원이 우리의 성공을 보장해 줄 것이오.   
  
삼대신은 그들의 정체인 거짓 신으로 낱낱이 드러남 것이며, 모로윈드는 자유를 얻으리라!  
  
—복스
