# 비토리아에게 보내는 편지

ID: ext-7fab1ab09c2526f95d62 / ESO 책 ID: 5473 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

비토리아,  
  
사울리니아의 암살자들에게 배를 찔렸어. 숨을 곳은 찾았지만, 오래 버티진 못해.  
  
우물을 확인해. 양동이 안에 열쇠를 숨겨 뒀어.  
  
마구간 지하실 문이 열릴 거야. 그게 칼로와 남은 비정규군에게 가는 길이야.  
  
언제나 당신을 사랑했어.
