# 루시우스의 쪽지

ID: ext-a5531c0653721978ddfb / ESO 책 ID: 509 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

탑에 갇혔다. 사방이 트롤 천지다. 물품은 저 꼭대기에 숨겨 뒀다, 놈들이 찾지 못하기를. 배가 고프다, 더는 못 기다리겠다 — 싸워서 빠져나가는 수밖에.  
  
누구든 이 글을 발견하거든, 부디 웨이넌 수도원의 마엘에게 물품을 전해 다오.  
  
— 루시우스
