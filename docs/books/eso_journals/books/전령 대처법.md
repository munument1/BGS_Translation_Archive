# 전령 대처법

ID: ext-11140ebeadcd81917cb3 / ESO 책 ID: 7303 / 한국어: 사용자 제공 kr.lang · 기존 게임 번역

기사단장에게,  
  
불변의 협회가 뒤포르 조선소로 던컨 제니스라는 전령을 보냈다. 그는 조선소에 대한 우리의 장악을 확인하고 그곳에서 벌이는 우리 활동을 바카로 볼로루스 경에게 보고하라는 명령을 받았다. 전령이 도착하면, 처리하라. 우리의 존재가 드러나는 일은 가능한 한 오래 비밀에 부쳐져야 한다.  
  
뒤포르 조선소는 우리 군대를 재건하려는 노력에 없어서는 안 될 곳이다. 필요하다 판단되는 어떤 수단을 써서라도 우리의 지배를 유지하라.
