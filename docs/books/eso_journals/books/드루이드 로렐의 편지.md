# 드루이드 로렐의 편지

<<1>>께,  
  
낯선 땅에서 유능한 조력자가 절실히 필요하던 차입니다. 적임자가 될 만한 분으로 당신의 이름을 전해 들었습니다.  
  
시간이 촉박합니다. 이 편지 뒷면에 제가 있는 곳을 그려 두었으니, 부디 형편이 닿는 대로 그곳으로 와 주십시오. 어떻게든 보답할 방도를 찾겠다고 약속드립니다.  
  
깊이 감사드리며,   
드루이드 로렐
