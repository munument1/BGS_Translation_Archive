# 자르디르의 표창

자르디르 대장에게,  
  
에본하트 조약에 바친 그대의 헌신적인 공로를 기려, 긍지와 기쁨으로 이 표창장을 수여하노라. 그대 부대에 속한 던머와 아르고니안 대원들의 보고를 보건대, 그대가 조약의 사명을 몸과 마음에 깊이 새기고 있음이 분명하도다.  
  
이대로 계속한다면 이 전쟁이 끝나기 전에 백인대장의 자리에 오를 것이다. 조약과 영광을 위하여!  
  
— 외눈 홀건, 스톤폴스 사령부
