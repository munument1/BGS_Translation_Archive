# 베람의 일지 3

ID: bk_BeramJournal3 / 플러그인: Morrowind_Korean_ReTranslation.esp

최악의 일이 벌어졌다. 오늘 아침 천장에서 바위가 떨어져 주 경사로를 정확히 덮쳤고, 경사로가 무너지며 부하 두 명이 죽었다. 남은 우리 셋은 아래에 고립됐다. 동굴 벽은 너무 가팔라 오를 수 없고, 마법사들은 길을 잃은 노동자 몇 명보다 더 중요한 일을 처리하느라 바쁜 모양이다. 물이 빠르게 줄어들어 노르부스와 길람을 동굴 깊숙이 보내 처음 조사할 때 놓친 자연 출구가 있는지 찾게 했다. 저주받을 마법사들. 이 장소가 안전하다고 했으면서. 위에서 대체 무슨 짓을 하는 거지? 벌레와 쥐는 왜 시간마다 더 난폭해지지? 그리고 왜 이렇게 빌어먹게 뜨거워지는 거야?
