# 타히엘의 일지

ID: bk_falljournal_unique / 플러그인: Morrowind_Korean_ReTranslation.esp

제가 개발 중인 주문에 필요한 정확한 공식을 찾은 것 같습니다. 이 공식을 이용하면 다른 사람에게 비용을 지불하지 않고도 먼 거리를 이동할 수 있을 것입니다.  
  
  
모든 게 순조롭게 진행된다면 내일 새로운 마법을 시험해 볼 겁니다. 발생 가능한 모든 문제점을 해결했다고 생각합니다. 이 마법을 사용하면 수백 마일에 달하는 먼 거리를 도약할 수 있습니다. 이전에는 누구도 이런 식으로 이동할 수 없었습니다. 땅에서 솟구쳐 올라 하늘을 가로지르면서도, 비행 마법처럼 방향 감각을 잃는 불편함도 없습니다.  
  
  
드디어 때가 왔습니다. 연구는 끝났고, 모든 계산도 꼼꼼히 확인했습니다. 제가 이 계획을 제안했을 때 그들은 저를 비웃었죠. 이제 제가 그들의 탑 꼭대기로 뛰어올라 성공을 외칠 때 누가 웃을지 두고 봅시다.
