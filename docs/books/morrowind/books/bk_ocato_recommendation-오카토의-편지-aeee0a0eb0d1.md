# 오카토의 편지

ID: bk_ocato_recommendation / 플러그인: Morrowind_Korean_ReTranslation.esp

이 편지를 받으시면 당신은 직책에서 물러나고, 대마법사 칭호는 다음 사람에게 수여하십시오: %PCName. 오늘부터 %PCName은 브바르덴펠의 모든 길드 업무를 담당하게 됩니다. 당신은 대마법사 칭호는 유지할 수 있지만, 길드 업무에서 완전히 손을 떼게 됩니다.

오카토
