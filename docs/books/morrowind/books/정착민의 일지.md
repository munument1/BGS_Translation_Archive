# 정착민의 일지

ID: bk_leggejournal / 플러그인: Morrowind_Korean_ReTranslation.esp

일기 1: 오늘 우리는 새로운 보금자리로 삼을 완벽한 장소를 찾았다. 레게라는 얼음 동굴인데, 근처 곰과 늑대들이 굴처럼 이용하는 것 같다. 걔네들은 쉽게 처리할 수 있을 것 같다.  
  
  
일기 2: 드디어 해냈어! 곰과 늑대들을 동굴에서 쫓아냈고, 우리는 벌써 이곳에 자리를 잡았어. 우리 후손들까지 레게의 안락함을 누리길!  
  
  
일기 3: 오늘 그 망할 곰 한 마리가 동굴에 들어왔어. 쫓아내긴 했는데, 저녁거리를 훔쳐 달아났지. 다행히 할아버지의 마법 반지가 있어서 곰들이 접근하지 못하게 막을 수 있었어.
