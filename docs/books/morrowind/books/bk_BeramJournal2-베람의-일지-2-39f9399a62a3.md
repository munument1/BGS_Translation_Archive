# 베람의 일지 2

ID: bk_BeramJournal2 / 플러그인: Morrowind_Korean_ReTranslation.esp

던전 하층 방은 처음 생각한 것보다 훨씬 공사하기 어렵다. 용암 흐름 가까이에서 작업하는 모양인지 동굴 벽의 바위가 유난히 단단하다. 제대로 된 조명도 설치하지 못해 보기 힘든데 이런 지연까지 필요하지는 않다. 새 화산 유리 도구를 주문했다. 그동안 부하 한 명이 다른 곳보다 부드러운 동굴 구역을 찾아 첫 방을 우회하고 그곳에서 작업을 계속했다. 최근 느껴지는 약한 진동을 걱정하는 사람도 있지만, 나는 텔바니가 하는 또 다른 속임수와 버섯 마법일 뿐이라고 확신한다. 그들은 이 장소가 안정적이라고 장담했다. 쥐와 벌레가 귀찮기는 해도 위협은 아니다. 이 창궐의 근원을 빨리 찾아 없앨 수 있기를 바란다. 이런 데 쓸 시간은 없다.
