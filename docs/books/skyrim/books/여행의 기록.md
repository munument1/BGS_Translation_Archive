# 여행의 기록

ID: 0008ACD1 / 플러그인: Skyrim.esm

우리는 유적을 확보하고, 우리의 발견물을 훔치려고 하는 사람, 특히 그 어떤 유적도 자신들이 탐색해야 한다고 생각하는 윈터홀드 대학의 사람들을 어떻게든 격퇴해 왔다.  
  
탐색대의 멤버를 이하에 적어둔다 :   
  
술라 트레바티우스(나): 탐색대 리더  
우마나 : 충실한 호위이자 동료  
발리 : 윈터홀드에 속하지 않은 마법사(찾아 내는데 매우 힘들었다.)  
엔드라스트 : 현지의 유명한 탐험가  
야그 : 다른 노동자들을 통솔하기 위해 고용한 몸집이 크고 힘센 여성  
지'다르 와 지'자르 : 노동자로 고용된 카짓 형제  
  
얼음을 깨고 나가는 것이 힘들기 때문에 앞으로 2, 3명의 노동자가 더 필요하다.  
  
우리는 먼저 피난소를 만든 뒤, 그 지역을 정찰했다. 빙하 아래에 평탄한 곳에 있는 작은 유적은 본 건물과는 이어져 있지 않은 것 같았으며, 여기서 찾아낸 탑의 흉벽으로 들어가는 길은 발견되지 않는다. 야그가 빙하 벽에서 유적으로 이어질지도 모르는 틈을 발견했다고 하여, 장비를 가지고 그곳으로 내려갈 길을 찾아보려 한다. 폭풍우가 다가오고 있다.
