# 우마나의 일기

ID: 000F0417 / 플러그인: Skyrim.esm

발리가 행방불명이 된지 1주일이 지났고, 지금 엔드라스트조차 행방불명이다. 우린 문 저 편으로 흘러내린 핏자국을 찾아냈는데 술라는 이렇게 생각했다. 행방불명된 이들이 새로운 출구를 찾아냈거나, 그게 아니면 뭔가 새로운 발견으로부터 우리를 따돌리려고 한다고.  
  
술라는 일이 진행되어야 한다고 계속 말한다. 우리는 유적의 다른 지역인 '기계실'로 간신히 들어갔다. 거기는 드워프가 자동 장치를 만드는 장소다.  
  
금속 물체들이 아직도 작동한다 걸 겨우 알아챘는데, 이 사실도 야그의 기분을 전혀 좋아지도록 하지 못햇다. 그녀는 실종된 카짓 형제는 실은 실종이 아니라고 생각했으며 술라에게 냉정한 눈초리를 보내고 있었다.  
  
식량은 아직는 충분하지만 머지않아 바닥날 것이다. 우린 폭풍우로 향하든지, 유적으로 더 파고 들지 빨리 결정해야 한다. 자고 있을 때 들은 비명의 잔향은 행방불명된 동료의 것일까, 아니면 내가 악몽을 꾼 것일까. 나로서는 알 수 없다.
