# 롤락에게 보내는 편지

ID: 00078621 / 플러그인: Skyrim.esm

이번엔 좋은 마차를 손에 넣었어. 편지는 벌써 보냈고, 그들이 어떻게 대답할까 기다려 보자.  
  
그 사이, 우리는 이것을 계속 부술 거야. 너는 우리의 체재를 유지하기 위해서 낮은 가격으로 나무를 계속 팔아 줬으면 해. 만약 금형에 좋은 가격이 붙으면, 당분간은 잘 지낼 수 있을 거야.  
  
아 그리고 너를 위해서 선반의 뒤의 통에 와인을 놓아뒀어. 특별 수당이라고 생각해 줘.
