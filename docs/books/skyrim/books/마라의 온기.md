# 마라의 온기

ID: 00053347 / 플러그인: Skyrim.esm

기뻐하세요.  
마라의 빛은 당신을 향해 빛나고 있습니다!  
  
마라의 자비는 영원하며 그녀의 온기는 온 세계에 널리 퍼져있습니다. 눈을 감고 하늘로 고개를 들어 우리의 운명을 정하는 빛의 은혜를 받으세요.  
  
마라 여신은 우리가 어떤 죄를 지었더라도 사해주십니다. 당신의 과오를 벗어던지고 영혼을 정화하세요! 당신의 어머니를 모시는 것처럼 여신을 섬기면, 여신께서는 결코 당신을 떠나거나 내치거나 저버리지 않으십니다.
