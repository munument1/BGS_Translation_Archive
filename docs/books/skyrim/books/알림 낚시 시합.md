# 알림: 낚시 시합

ID: 05000B2E / 플러그인: ccBGSSSE001-Fish.esm

알림  
  
이 몸께선 이 지면을 빌어 낚시 시합 공고문을 읽는 모두에게 도전을 거는 바요! 우리의 패기를 시험하고 정말로 누가 카스 강변의 가장 위대한 낚시꾼인지 내기해봅시다.  
  
난 액수에 상관없이 같은 돈을 걸겠으니, 판돈은 얼마든지 원하는 만큼 거시오. 경고하는데 날 이긴 자는 아무도 없소. 사실 나와 대결한 모든 도전자는 두 번 다시 모탈에 발을 들여놓질 못했는데, 틀림없이 수치심 때문일 거요.  
  
대결할 자신이 있다면 부두로 날 만나러 오시오.
