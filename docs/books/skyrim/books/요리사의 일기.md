# 요리사의 일기

ID: 000951AE / 플러그인: Skyrim.esm

고기다!  
고기, 고기, 고기!  
그들이 항상 원하는건 고기 뿐이다!  
  
그들은 맛있게 구워진 파를 나의 얼굴에 던져버렸다.  
  
그들에게 물고기나 사슴고기를 가져오면 요리해주겠다고 말했지만 그들의 급료를 도박으로 탕진할 뿐이다.  
  
하지만 고기를 손에 넣는 방법은 분명 있을 것이다.
