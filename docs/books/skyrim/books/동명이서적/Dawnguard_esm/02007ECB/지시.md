# 지시

ID: 02007ECB / 플러그인: Dawnguard.esm

<Alias=Capital>에서 어느정도 체류하라. <Alias=Jarl>의 궁정에 침투하라. 할 수 있으면 부드러운 방법으로 야를을 우리의 이익을 위해 움직이게끔 유도하라. 그것이 불가능할 경우에는, <Alias.PronounObj=Jarl> 또는 <Alias.PronounPosObj=Jarl> 궁정의 일원을 우리 가족으로 초대하라. 피의 갈증을 함께 나누는 자들을 우리의 공통된 이익으로 이끄는 것이 훨씬 더 쉬운 법이다.
