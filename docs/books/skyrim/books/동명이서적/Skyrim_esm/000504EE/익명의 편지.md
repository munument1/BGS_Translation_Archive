# 익명의 편지

ID: 000504EE / 플러그인: Skyrim.esm

스카이림의 자손들에게  
  
내가 누구인가는 내가 알고 있는 것만큼 중요하지 않다. 나는 제국놈들의 친구는 아니라고 할 수 있다.  
  
여러가지 방법으로 나는 <Alias=Steward>이(가) <Alias.PronounPos=Steward>의 과거에서 꽤 부끄러운 경솔한 행위를 해 왔던 것을 눈치챘다. 또, <Alias.Pronoun=Steward>는 어리석게도 이 건에 관한 증거를 숨기고 있는 것을 우연히 알았다.  
  
증거를 찾아내면 <Alias=Hold>에서의 싸움을 돕도록 <Alias.PronounObj>를 '설득'할 수 있을지도 모른다. 제국과 <Alias.PronounRef=Steward> 둘중 하나를 선택하도록 하면, <Alias.Pronoun=Steward>는 반드시 후자를 선택할 것이다.
