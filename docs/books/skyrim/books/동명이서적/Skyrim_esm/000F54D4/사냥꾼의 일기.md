# 사냥꾼의 일기

ID: 000F54D4 / 플러그인: Skyrim.esm

그 짐승들을 며칠동안 추적한 뒤에, 드디어 그 놈들의 소굴을 알아냈다고 생각한다. 이 동굴 속 깊은곳에 그놈들의 소굴이 있는 것 같다. 우리가 처음 생각한 것 보다 더 많을 수도 있다. 하지만 이상한 기둥과 파이프들을 보니 여기가 어떤 유적인 것 같다.  
  
할머니께서는 '이런 장소는 처음 발견한 자를 기다리고 있는 보물이 흘러넘치고 있다'고 항상 말씀하셨기 때문에 우리는 천막을 치고 동물들이 없는지 확인 후, 가치가 있는 물건들이 있는지 찾아보기로 했다.
