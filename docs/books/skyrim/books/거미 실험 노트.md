# 거미 실험 노트

ID: 02017072 / 플러그인: Dragonborn.esm

몇 가지의 조합만 시도해보았으나, 조짐이 좋아 보인다. 내가 지금까지 발견한 것은 다음과 같다:  
 루비 + 백색 고치 =  화염 거미  
루비 + 손상된 고치 = 폭발형 화염 거미  
루비 + 소금 가루 + 손상된 고치 =       4 3  
루비 + 소금 가루 + 백색 고치 = 불꽃 망토 거미  
[pagebreak]  
  
    결과를 보면, 마치 보석의 순도가 어떤 알 수 없는 방법으로 작업과정을 향상시킨 것처럼 보인다. 아마도 내가 완벽한 루비를 얻는다면...  
  
    이전의 실험의 재료들 중 대부분을 어떤 것과 혼합한다면 그것은 새로운 것을 만들어 낼 수 있을것이라는 이론을 수립했다.  
  
   다이아몬드와 석류석에 대하여 조금 더 자세한 조사에 따르면 그 두 가지에는 필수적으로 요구되는 힘이 포함되어 있지 않는 것으로 보인다. 이전의 실험에서 보디시피, 루비가 동작한다는 것에 대해선 분명하다. 다음에는 자수정, 에메랄드, 사파이어까지 그것들이 어떤 반응을 하는지 볼 것이다.  
  
   다른 종류의 거미들이 있다는 것은 분명하다. 다른 종류의 작업과정에서 발생할지도 모른다. 우리는 항상 지켜봐야 한다. 우리가 발견한 새로운 것들이 무엇이든 간에, 상호작용의 원천은 아주 가까이에 있을 것이다.
