# 던가드 공문서

ID: 020034DC / 플러그인: Dawnguard.esm

던가드의 명령,  <Alias.Race=Player> 종족 <Alias=Player>은(는) 흡혈귀 범죄를 저지른 죄로 인하여 죽음을 받게 될 것이다. 우리의 권위와, 야를의 암묵적인 동의 하에, 이 공문서를 소지하고 있는 자는 사형 선고를 받은 <Alias.Pronoun=Player>가 어디로 도망치건 정의의 철퇴를 내릴 권한을 가진다.
