# 어샤에게 보내는 편지

오 어샤, 당신이 편지를 써서 당신에게 문제가 없다는 것을 알려주길 바래요. 아버지가 당신의 부족한 재산은 눈감고 진정한 당신을 봐 주도록 설득했어요.  
  
집으로 돌아오세요. 걱정할 필요는 없으니. 당신을 기다리겠어요, 내 사랑.
