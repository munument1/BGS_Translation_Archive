# 발머의 지시

ID: 00093CF6 / 플러그인: Skyrim.esm

포렐호스트(Forelhost) 유적에서 드래곤 교단으로부터 가면을 되찾아라.  
  
발각되면 장교인 척 하라. 스카이림의 바보들은 변장을 알아챌만큼 똑똑하지는 않아.  
  
가면을 손에 넣으면 곧바로 미궁(Labyrinthian)으로 가지고 오라.
