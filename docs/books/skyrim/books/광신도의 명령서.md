# 광신도의 명령서

ID: 020331C2 / 플러그인: Dragonborn.esm

레이븐 락에 정박중인 노던 메이든호에 승선하라. 윈드헬름에 도착하면 수색을 시작하라.  <Alias=Player>(이)라고 알려진 가짜 드래곤본이 솔스트하임에 도착하기 전에 찾아내고 <Alias.Pronoun=Player>를 죽여라.   
  
  
임무를 완수하고 돌아오라, 미락님이 매우 기뻐하실 것이다.
