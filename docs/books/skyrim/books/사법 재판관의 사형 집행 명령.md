# 사법 재판관의 사형 집행 명령

ID: 000BA0BE / 플러그인: Skyrim.esm

<Alias.Race=Player> 종족인 <Alias=Player>(이)라는 이름을 가진 자를 조심하라. 놈은 탈모어의 적이다. 적극적으로 이쪽 행동을 방해해서 상당한 피해를 입혔다. 만약 발견하게 된다면, 증오를 담아 <Alias.PronounObj=Player>를 죽여라.  
  
충고하건대, <Alias.Pronoun=Player>는 매우 위험한 인물이다. 스스로를 지킬 능력도 충분하다. 만약 현지 관헌에게 붙잡힐 경우에는 우리의 도움을 기대하지 않도록 하라.  
  
알드머 자치령의 영광을 위하여!
