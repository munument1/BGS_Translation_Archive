# 살마에게 보내는 편지

ID: 000E7F3B / 플러그인: Skyrim.esm

사랑하는 딸에게  
지나치게 널 걱정하는 것처럼 보이겠지만 난 여전히 좋게 생각하지는 않는단다.  
세상은 네가 생각하는 것보다 훨씬 위험한 곳이고, 보물찾기는 어리석은 사람들이나 하는 일인데 말이야.  
어딜 가든지 조심하고, 빔-자에게서 눈을 떼지 말거라.  그는 널 지켜주겠지만, 너무 믿어서는 안된다. 그리고 이런 장난에 질리거든 곧장 집으로 돌아오도록 하거라.
