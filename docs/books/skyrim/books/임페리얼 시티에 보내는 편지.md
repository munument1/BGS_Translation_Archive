# 임페리얼 시티에 보내는 편지

ID: 02026AE8 / 플러그인: Dragonborn.esm

이것은 프로스트모스 요새를 둘러싼 위협에 관한 지시를 받고자 시로딜에 있는 제국 의회에 보내는 세번째 편지입니다.  
  
상당한 규모의 다크 엘프 부대가 솔스트하임의 남서쪽에 요새를 건설했습니다. 나는 그들에게 항복할 기회를 충분히 제공했으나, 그들과 소통하려는 모든 시도는 실패로 끝나버렸습니다.  
  
다른 명령이 내려지기 전까지는 이 침입자들을 솔스트하임에서 몰아내고 프로스트모스 요새의 안전을 확보하기 위해 가능한 한 모든 수단을 강구할 것입니다.
