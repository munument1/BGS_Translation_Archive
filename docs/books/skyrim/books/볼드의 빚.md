# 볼드의 빚

ID: 00072B13 / 플러그인: Skyrim.esm

이 문서는 리프튼의 볼드(차주)를 리프튼 의 메이븐 블랙-브라이어(대주)에게 지고 있던 빚과 이자로부터 방면한다. 이 문서는 대주가 빚이 모두 청산되었다고 여길 때까지 안전한 장소에 보관되어 있어야만 한다. 차주가 사망한 경우에는 리프튼의 행정관의 결정에 의해, 남겨진 돈이나 자산으로 갚는다.
