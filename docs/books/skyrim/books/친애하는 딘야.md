# 친애하는 딘야

ID: 0203A4B2 / 플러그인: Dragonborn.esm

친애하는 딘야,  
  
당신 아버지가 우리 사이를 인정하지 않고 있다는 점을 알고 있습니다,하지만 우리의 관계를 개선할 수 있는 일이라면 어떤 것이든 기꺼이 할 용의가 있습니다. 우리에 관련된 잡담과 소문들에 관해 그와 개인적으로 대화를 해야 할 시간이 되었다고 생각됩니다. 당신을 사랑하고, 온 세상이 알게 되어도 두렵지 않습니다. 고려해 보시기 바랍니다.  
  
모딘 (Modyn)  
  
------------  
주석   
딘야라고 되어 있지만, 드레일라 (Dreyla)에게 보내는 편지입니다.   
베데스다에서 확장팩 제작시에 드레일라라는 NPC의 이름이 처음에는 딘야였다가, 이미 리프튼에 존재하는 여 사제인 딘야 (Dinya Balu)와 혼동을 피하기 위해 이름을 바꾸었으나, 본문은 그대로인 듯 합니다.
