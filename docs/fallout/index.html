기록 보존 원칙

이 사이트는 비공식·비상업 팬 프로젝트입니다. 폴아웃 3·뉴 베가스·4의 원본 게임 ESM에서 문서 식별자를 추출했으며, 기존 외부 목차도 함께 제공합니다. 본문 원문은 로컬 작업 자료로 보관하고 있습니다. 공개 색인에 원문 전문은 포함되지 않습니다. 저작권은 각 권리자에게 있으며, 한국어 본문은 보관된 기존 번역 사전에서 연결했습니다. 기록별 번역 출처를 확인할 수 있으며, 아카이브 자체의 문장 검수와 게임 내 사용 여부 확인은 진행 전입니다.
