기록 보존 원칙

게임 문서와 EPUB 녹취를 기존 한글 번역에 대조한 비공식 팬 서고입니다. 기존 게임 번역을 본문으로 사용하며, EPUB 영문은 참조 자료로 유지합니다. 각 기록의 번역 출처를 확인할 수 있습니다. 번역 연결은 새 문장 검수나 게임 내 사용 여부 확인을 뜻하지 않으며, 원문과 번역의 권리는 각 권리자에게 있습니다.
