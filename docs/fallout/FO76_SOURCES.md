# 폴아웃 76 공식 한국어 읽기 자료

사용자가 지정한 Steam 설치본의 `SeventySix.esm`과 `SeventySix - Localization.ba2`에서 공식 한국어 읽기 자료 **2,957개 항목**을 황무지의 기록에 보충했습니다. 설치 실행 파일의 표시 버전은 **1.7.27.11**이며, 현재 서버의 최신 데이터와 동일하다고 주장하지 않습니다.

| 종류 | 공개 항목 |
|---|---:|
| 메모·문서 | 1,615 |
| 홀로테이프 | 477 |
| 터미널 | 865 |
| 합계 | 2,957 |

같은 터미널의 본문과 연결된 하위 메뉴를 한 항목에서 읽습니다. 터미널 레코드 2,259개가 홀로테이프·루트 터미널의 묶음에 연결되며, 이는 공개 터미널 항목 수와 다릅니다. 감독관의 기록 18편, 생존자의 이야기 10편, 에이브락소다인 테이프 15편 등 **40개 연속 기록 묶음**을 포함합니다. 번호가 아닌 장소·인물 부제가 붙은 가족별 기록도 명시적인 동일 시리즈일 때 묶었습니다. 감독관의 기록은 장소 제목 순서이며 플레이 순서를 뜻하지 않습니다.

## 원본 연결

- BA2 일반 아카이브의 인덱스로 `seventysix_ko.strings`, `.dlstrings`, `.ilstrings`를 읽었습니다. ESM은 읽기 전용으로 처리하고, 압축 레코드 크기를 확인했습니다.
- 제목은 FULL, 메모 본문은 BOOK.DESC, 터미널은 WNAM/BTXT/UNAM/RNAM과 TNAM 하위 메뉴 참조를 사용합니다. 메뉴 제목은 실제 직전 ITXT 필드에 대응시킵니다. 소지품 설명이나 설계도 이름을 읽기 본문으로 바꾸지 않습니다.
- 음성 홀로테이프는 NOTE.SNAM → SCEN의 단계·동작 → DIAL → INFO.NAM1을 따라 공식 자막을 수록합니다. 공유 INFO 참조도 따라갑니다. 게임 조건에 따른 대체 응답이 있는 경우 읽기 화면에 안내하며, 이를 모두 한 번에 재생되는 대사라고 주장하지 않습니다.
- FormID, 문자열 ID, 필드, 하위 인덱스, 한국어 문자열 해시와 원본 파일·문자열 테이블 해시를 보존합니다. 인식한 현지화 필드에서 한국어 문자열 ID 누락은 0개입니다.
- 사용한 레코드 정의 참고: [xEdit의 Fallout 76 정의](https://github.com/TES5Edit/TES5Edit/blob/dev-4.1.6/Core/wbDefinitionsFO76.pas). `NW.esm`은 설치 설정에서 별도 `sBabylonMasters`로 지정된 모드 원본이므로 일반 SeventySix 자료 위에 덮어쓰지 않았습니다.

## 제외와 표시

본문 없는 설계도·아이템, 이미지뿐인 자료, 명시적인 테스트·디버그·삭제용 EditorID, 텍스트 없는 음원·프로그램은 공개 읽기 목록에서 제외했습니다. 공식 한국어 테이블에도 영문 산문만 남은 홀로테이프 3개는 한국어 본문으로 표시하지 않았습니다. 이들을 게임 번역 전체의 미번역 수로 해석하지 않습니다. 숫자 암호·체스 기보·암호화된 문자열은 번역 대상 문장이 아니므로 원본 기호 그대로 수록하고 별도로 표시합니다.

실행 시 인물·장소를 넣는 변수는 원래 표기를 유지합니다. 텍스트가 함께 있는 게임 이미지는 `[게임 내 이미지]` 안내로 표시합니다. 레코드가 파일에 존재한다는 사실과 현재 서버에서 실제로 등장한다는 사실은 구분하며, 배치·조건·서버 가용성을 전수 검증한 목록은 아닙니다. 게임 원본 바이너리·음원·문자열 테이블 전체는 공개 저장소에 넣지 않습니다.

기존 폴아웃 1·2·택틱스·3·뉴 베가스·4 기록 4,281개의 본문과 ID는 유지했습니다. 전체 공개 읽기 목록은 **7,238개**입니다.
