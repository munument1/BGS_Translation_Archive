# Contributing

## 기본 규칙

1. 실제 게임 플러그인(ESP/ESM)보다 정규화된 번역 데이터를 우선 제출합니다.
2. 기존 식별자(FormID, EditorID, 레코드/필드 구조)를 임의로 변경하지 않습니다.
3. 줄바꿈, 제어문자, 태그가 의미를 가지는 항목은 원래 구조를 보존합니다.
4. AI 번역은 `status: "ai"` 등으로 사람이 검수한 데이터와 구분합니다.
5. 사람이 문맥까지 확인한 경우 `reviewed`, 최종 확정 데이터는 `verified`를 사용합니다.
6. 용어 변경은 가능하면 `dictionaries/`의 용어 사전에도 반영합니다.
7. 원문 또는 외부 번역 자료를 가져오는 경우 재배포 조건과 출처를 확인합니다.

## 권장 상태 흐름

```text
raw -> ai -> reviewed -> verified
```

AI를 사용하지 않은 번역은 필요한 단계를 건너뛸 수 있습니다.

## 파일 인코딩

- JSONL / JSON / Markdown: UTF-8
- 줄바꿈: LF 권장
- JSONL 한 줄 = 하나의 번역 항목
