# Skyrim

The Elder Scrolls V: Skyrim 번역 데이터 아카이브입니다.

권장 하위 구조:

```text
BaseGame/   본편 번역
DLC/        공식 DLC 및 공식 추가 콘텐츠
Mods/       모드 번역
```

실제 데이터가 추가되는 범주부터 하위 폴더를 생성합니다.

## 스카이림 번역 데이터 원천

이미 공개된 서적 한국어 자료는 `docs/books/skyrim/`과
`sources/skyrim_books/`에서 별도로 관리됩니다.
스카이림 SE/AE 일반 게임 문자열과 공식 표기의 참고 출처로는
[Skyrim_Translator_v6](https://github.com/servaltullius/Skyrim_Translator_v6)의
용어집과 `Skyrim_Latest_Kor` 문자열들이 있습니다.

**이 외부 프로젝트의 용어집·한국어 문자열 전체에 적용되는
재배포 권한은 확인되지 않았으므로**, 이번 데이터 이관에서는
원문 파일과 타인의 번역 데이터 전체를 이 저장소에 복제하지
않았습니다. 레코드별 문맥과 사용 권한이 확보된 후
`BaseGame/`, `DLC/`, `Mods/`로 분리해 수록할 수 있습니다.
